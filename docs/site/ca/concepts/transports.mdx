`transport` tria el transport TCP. `udp_transport` pot definir una ruta diferent per a UDP; si s'omet, hereta `transport`.


## Com pots comprovar el resultat

Tria TCP per a la primera connexió. Quan funcioni als dos extrems, prova QUIC o camins separats per a TCP i UDP. Canvia una sola opció cada vegada i torna-ho a provar amb la mateixa aplicació; Umbra no canvia de transport automàticament.

## Per on començar

Utilitza TCP per a la primera connexió o si UDP no està disponible. Activa mux per reutilitzar connexions o desactiva'l per a Vision dedicat. Prova QUIC quan UDP funcioni, especialment si TCP pateix reinicialitzacions injectades. Combina rutes amb TCP i `udp_transport = "quic"`. Comprova primer connectivitat i després latència, estabilitat i cabal amb la mateixa aplicació.

## Reutilitzar connexions TCP

```toml
transport = "tcp"
mux = true
```

Les peticions comparteixen connexions xifrades. Les finestres adaptatives segueixen consum i temps d'anada i tornada dins dels pressupostos. Una pèrdua TCP pot fer esperar les peticions de la mateixa connexió. Fes servir versions compatibles.

## TCP / Vision dedicat

```toml
transport = "tcp"
mux = false
```

Cada petició té la seva connexió. Després de negociar l'autenticació, els registres TLS 1.3 aptes es reenvien sense xifratge extern ni encapsulació addicional. La resta continua xifrada. Mantén HTTPS a les aplicacions. El reenviament funciona en espai d'usuari; el rendiment depèn del dispositiu i la xarxa.

## QUIC

```toml
transport = "quic"
```

QUIC utilitza UDP. Activa `udp_listen`, obre el port i tria un lloc QUIC accessible. Els fluxos separats recuperen pèrdues independentment; cada flux fiable lliura en ordre. Umbra també transporta associacions UDP en fluxos QUIC fiables: una pèrdua pot retardar les dades següents.

Quinn BBR és el predeterminat; també hi ha `cubic` i `new-reno`. Controlen l'enviament QUIC local, separat del TCP del sistema.

## Dues rutes, una entrada

Client:

```toml
transport = "tcp"
udp_transport = "quic"
mux = false
socks_listen = "127.0.0.1:1080"
```

Servidor:

```toml
listen = "0.0.0.0:443"
udp_listen = "0.0.0.0:443"
```

Conserva els altres camps de la configuració completa. Les aplicacions utilitzen un SOCKS5. `udp: true` permet UDP a Clash; TCP segueix `transport`. Ajusta la configuració si canvia la xarxa: el canvi TCP/QUIC és manual.

## Farciment i escriptura de la negociació

El farciment afegeix dades de longitud aleatòria al principi i després menys sovint per suavitzar patrons de longitud, consumint amplada de banda. `tcp_evasion = "segment"` divideix ClientHello en escriptures ordenades; el sistema determina els paquets reals. Prova `off` si hi ha incompatibilitats. Geneva DSL no està disponible.
