El TOML del client defineix l'extrem remot i SOCKS5 local.

## Configuració mínima

Substitueix adreça, domini i identitat:

```toml
server = "198.51.100.10:443"
transport = "tcp"
public_key = "<X25519_PUBLIC_BASE64>"
short_id = "<SHORT_ID_HEX>"
server_name = "cover.example"
fingerprint = "chrome-latest"
mldsa_verify = "<MLDSA_VERIFY_BASE64>"
socks_listen = "127.0.0.1:1080"
```

## Camps

| Camp | Valor per defecte / requisit | Significat |
|---|---|---|
| `server` | Obligatori | Servidor Umbra, host:port |
| `transport` | Obligatori | Transport principal: tcp o quic |
| `udp_transport` | `transport` | Transport UDP; hereta transport si s’omet |
| `public_key` | Obligatori | Identitat pública X25519, 32 bytes descodificats |
| `short_id` | Obligatori | Un short ID admès pel servidor |
| `server_name` | Obligatori | SNI admès pel servidor |
| `fingerprint` | Obligatori | Nom del perfil d’empremta integrat |
| `mldsa_verify` | Obligatori | Clau de verificació ML-DSA, base64 no buit |
| `socks_listen` | Obligatori | Escolta SOCKS5 local, sense autenticació |
| `spider_path` | `"/"` | Camí del lloc real; comença per /, sense CR/LF |
| `mux` | `true` | Mux xifrat; false tria TCP/Vision dedicat |
| `padding_scheme` | `"default"` | Política de farciment intern |
| `tcp_evasion` | `"segment"` | Escriptures ordenades de ClientHello |

## Verificar la identitat

`public_key` és la clau X25519 del servidor, de 32 bytes un cop descodificada. `mldsa_verify` és la clau de verificació Base64 no buida corresponent. Obté-les per un canal de confiança. `short_id` i `server_name` han de coincidir amb les llistes del servidor.

## Triar transports

`transport` és obligatori: `tcp` o `quic`. UDP n'hereta el valor final tret que s'indiqui `udp_transport`, que només afecta UDP. TCP utilitza `mux = true` per defecte; false selecciona Vision dedicat.

## Accés local i perfils

Fes servir `127.0.0.1:1080` a `socks_listen`, perquè no hi ha contrasenya. `fingerprint` tria el perfil de negociació. `chrome-latest` i `chrome-150-macos` fan servir Chrome 150 actualment; els àlies canvien amb les versions.

`spider_path` val `/` per defecte i s'utilitza per al comportament del lloc real quan no s'autentica una sessió Umbra. Ha de començar per `/` i no contenir retorns de carro ni salts de línia. La CLI substitueix camps abans de validar. El rendiment va a `[performance]`; comença amb els valors predeterminats.
