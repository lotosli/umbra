## Visió general

Aquestes plantilles seleccionen modes després d’emplenar identitat i adreces seguint l’inici ràpid. Substitueix tots els marcadors: no són credencials completes. No publiquis mai els fitxers ja emplenats amb secrets reals. Cada rol fa servir el mateix binari i no necessites un altre client només per triar un transport UDP diferent del principal.

## Detalls

La multiplexació TCP xifrada utilitza transport=tcp i mux=true; els clients alpha activen el control adaptatiu per defecte. Per a TCP/Vision dedicat, tria transport=tcp i mux=false. El trànsit TLS 1.3 elegible es pot transferir després de l’intercanvi autenticat de frontera; la resta continua xifrada. No existeix cap paràmetre vision addicional i el reenviament es manté en espai d’usuari.

### TCP multiplexat

```toml
transport = "tcp"
mux = true
```


### TCP / Vision dedicat

```toml
transport = "tcp"
mux = false
```


### TCP / Vision + QUIC UDP

```toml
transport = "tcp"
udp_transport = "quic"
mux = false
socks_listen = "127.0.0.1:1080"
```


### Plantilla del servidor

```toml
listen = "0.0.0.0:443"
udp_listen = "0.0.0.0:443"
```


### QUIC natiu

```toml
transport = "quic"
```


### Node SOCKS5 de Clash

```yaml
proxies:
  - name: Umbra
    type: socks5
    server: 127.0.0.1
    port: 1080
    udp: true
```


## Verificació i límits

Per tenir TCP/Vision i QUIC UDP en una instància, afegeix udp_transport=quic i habilita listen i udp_listen al servidor. Per a QUIC principal, selecciona transport=quic i omet udp_transport perquè hereti quic. La destinació ha d’oferir QUIC/HTTP3 real. udp: true a Clash permet UDP ASSOCIATE mentre TCP segueix el transport principal. Canvia un ajust cada vegada i mesura abans d’alterar el farciment o la segmentació per defecte.
