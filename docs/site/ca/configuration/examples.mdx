Combina aquests fragments amb una configuració completa després d'omplir adreces, claus i lloc de cobertura.

## Compartir connexions TCP

```toml
transport = "tcp"
mux = true
```

Les peticions reutilitzen connexions. El control de flux adaptatiu és actiu per defecte i necessita un servidor compatible.

## TCP / Vision dedicat

```toml
transport = "tcp"
mux = false
```

Després de negociar l'autenticació, Vision reenvia registres TLS 1.3 aptes ja xifrats. La resta continua xifrada. No cal cap altra opció Vision.

## Vision per a TCP, QUIC per a UDP

Client:

```toml
transport = "tcp"
udp_transport = "quic"
mux = false
socks_listen = "127.0.0.1:1080"
```

Servidor:

```toml
listen = "0.0.0.0:443"
udp_listen = "0.0.0.0:443"
```

Obre TCP i UDP i fes servir un lloc QUIC/HTTP/3 accessible. N'hi ha prou amb un procés a cada extrem.

## QUIC per als dos tipus de petició

```toml
transport = "quic"
```

Omet `udp_transport` per heretar QUIC. Elimina una opció anterior o canvia-la a `quic`.

## Node local per a un client compatible amb Clash

```yaml
proxies:
  - name: Umbra
    type: socks5
    server: 127.0.0.1
    port: 1080
    udp: true
```

Afegeix-lo a la llista i al grup existents. `udp: true` permet UDP; TCP segueix `transport`. Envia directament l'adreça del servidor Umbra per evitar bucles. Canvia un mode cada vegada i prova TCP i UDP per separat.
