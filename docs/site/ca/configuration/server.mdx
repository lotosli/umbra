El servidor utilitza TOML. Per a la primera instal·lació, segueix la guia del servidor.

## Configuració mínima

Substitueix els marcadors i `cover.example`:

```toml
listen = "0.0.0.0:443"
private_key = "<X25519_PRIVATE_BASE64>"
short_ids = ["<SHORT_ID_HEX>"]
dest = "cover.example:443"
server_names = ["cover.example"]
max_time_diff = "120s"
mldsa_seed = "<MLDSA_SEED_BASE64>"
```

## Camps

| Camp | Valor per defecte / requisit | Significat |
|---|---|---|
| `listen` | Obligatori | Adreça numèrica d’escolta TCP |
| `udp_listen` | `—` | Escolta QUIC UDP opcional; omet per desactivar |
| `private_key` | Obligatori | Clau privada X25519, base64, exactament 32 bytes |
| `short_ids` | Obligatori | Llista no buida d’ID hexadecimals de 0–8 bytes |
| `dest` | Obligatori | Destinació real de retorn, host:port |
| `server_names` | Obligatori | Llista no buida de SNI admesos |
| `max_time_diff` | Obligatori | Desfasament permès, almenys un segon |
| `mldsa_seed` | Obligatori | Llavor ML-DSA, base64, exactament 32 bytes |
| `prebuild` | `true` | Actualització periòdica; comprovació inicial obligatòria |
| `padding_scheme` | `"default"` | Política de farciment intern |
| `tcp_evasion` | `"segment"` | Escriptures ordenades de ClientHello |

Posa els paràmetres de rendiment a `[performance]`.

## Adreces i dominis

`listen` i `udp_listen` necessiten IP numèrica i port: `0.0.0.0:443` o `[::]:443`. `dest` admet un nom d'amfitrió. `server_names` necessita almenys un nom que compleixi longitud i sintaxi ASCII, sense espais. Utilitza dominis del lloc real; el client en tria un.

## Claus i identificadors

`private_key` i `mldsa_seed` són Base64 i es descodifiquen en 32 bytes cadascun. Utilitza les sortides de `keygen`. `short_ids` conté almenys una cadena hexadecimal de longitud parella, fins a 16 caràcters; també s'accepta la cadena buida. El valor del client ha de coincidir.

## Hora i actualització del lloc

`max_time_diff` admet `ms`, `s`, `m`, `h`, o segons sense sufix; la durada final és d'almenys un segon. Revisa els rellotges abans d'ampliar la tolerància. El lloc es comprova a cada arrencada; `prebuild`, actiu per defecte, controla les actualitzacions posteriors.

## Opcions de línia d'ordres

Les opcions proporcionades substitueixen els camps abans de validar valors obligatoris, tipus i camps desconeguts. La CLI usa guionets, com `--udp-listen`; TOML, guions baixos. Desa secrets en fitxers protegits per evitar l'historial i els arguments de processos.
