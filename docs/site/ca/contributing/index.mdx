Llegeix `CONTRIBUTING.md` i `AGENTS.md` abans de començar.

## Acordar el canvi

Les funcions segueixen OpenSpec: proposta, requisits i escenaris, aprovació humana i implementació. La documentació ha de reflectir el codi actual i conservar els identificadors en les set llengües.

## Verificar la feina

Executa format, lint, proves, dependències i cobertura segons el canvi. La cobertura de línies Rust ha de ser com a mínim del 90 %. Els analitzadors necessiten casos límit i d'error; criptografia i empremtes requereixen vectors o captures corresponents.

```sh
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
cargo nextest run --workspace
cargo deny check
cargo xtask coverage
npx --yes @fission-ai/openspec@latest validate --all --strict
```

El web té controls propis a `docs/website-development.md`. Centralitza dependències i comprova llicències.

## Enviar a revisió

Utilitza Conventional Commits i explica problema, abast i validació a la PR. Qui contribueix ha d'entendre, revisar i provar la feina assistida per IA i declarar el contingut generat substancial. Retira credencials reals, infraestructura privada i vulnerabilitats no publicades. Umbra té llicència MIT.
