El mateix programa funciona com a client o servidor. Fes servir la mateixa versió als dos extrems i el fitxer adequat per al sistema i l'arquitectura de cada equip.

## Descarregar

Obre les [versions de GitHub](https://github.com/lotosli/umbra/releases). La taula identifica les plataformes de compilació; els fitxers disponibles depenen de cada versió.

| Plataforma | Arquitectura | Objectiu de compilació |
|---|---|---|
| macOS | Apple Silicon | `umbra-aarch64-apple-darwin` |
| macOS | Intel | `umbra-x86_64-apple-darwin` |
| Linux | x86_64 | `umbra-x86_64-unknown-linux-gnu` |
| Linux | aarch64 | `umbra-aarch64-unknown-linux-gnu` |
| Windows | x86_64 | `umbra-x86_64-pc-windows-msvc.exe` |

## Instal·lar el programa

Al macOS o Linux, descomprimeix el fitxer si cal i dona permís d'execució al programa. Pots reanomenar-lo `umbra` i posar-lo en un directori de `PATH`. Al Windows, executa l'arxiu `.exe` des d'un terminal o afegeix-ne la carpeta a `PATH`. Llegeix les notes de versió i comprova el fitxer amb la informació de verificació publicada.

## Compilar el codi font

Fes servir la versió de Rust fixada al repositori, 1.96.1:

```sh
git clone https://github.com/lotosli/umbra.git
cd umbra
cargo build --release
./target/release/umbra --help
```

El programa queda a `target/release`, amb extensió `.exe` al Windows.

## Comprovar la instal·lació

Executa `umbra --help`, amb el camí complet si cal. Hi han d'aparèixer `server`, `client` i `keygen`. Després genera les claus i configura els dos extrems. La guia de desplegament explica com executar-lo en segon pla.
