Umbra és un servidor intermediari de codi obert que allotges tu mateix. Executa el servidor a la teva infraestructura i el client al dispositiu, i connecta les aplicacions al seu punt d'accés SOCKS5 local. Tu tries el servidor, el transport i les aplicacions que l'utilitzen.

## Per què Umbra?

### Un lloc web real com a cobertura

El teu client s'autentica per establir la connexió. La resta de connexions es reenvien al lloc web configurat i en reben la resposta habitual.

### Una entrada per a TCP i UDP

Un sol client i un sol servidor poden enviar les peticions TCP per TCP i les UDP per QUIC. Les aplicacions continuen fent servir una única adreça SOCKS5.

### Menys feina repetida

La multiplexació permet reutilitzar connexions. Vision pot reenviar directament registres TLS 1.3 ja xifrats que compleixin les condicions necessàries, reduint el xifratge extern i l'encapsulació.

### Conserva les eines habituals

Les aplicacions amb SOCKS5 s'hi connecten directament. Un client compatible amb Clash pot mantenir la interfície i les regles mentre Umbra gestiona la connexió remota. Tampoc cal sol·licitar ni renovar un certificat d'una CA pública per al node Umbra.

## Què necessites

Un servidor accessible, la mateixa versió d'Umbra als dos extrems, un lloc TLS 1.3 real accessible des del servidor i una aplicació amb SOCKS5. Umbra funciona des de la línia d'ordres, amb llicència MIT i sense compte d'Umbra. Tu proporciones i mantens el servidor. Els nodes VLESS, VMess i Trojan continuen amb els seus clients; una connexió Umbra necessita Umbra a tots dos extrems.

## Comença amb una aplicació

Segueix l'inici ràpid abans d'afegir regles o QUIC. Tu decideixes quines aplicacions utilitzen el servidor intermediari. La versió actual és **1.0.0-alpha**: conserva un programa i una configuració que funcionin. L'entrada local no té contrasenya; limita-la a `127.0.0.1:1080`. El model de seguretat n'explica els detalls.
