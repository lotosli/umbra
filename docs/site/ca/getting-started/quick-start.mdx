Comença amb TCP. Instal·la la mateixa versió al servidor i al dispositiu client. El client ha de poder arribar al servidor, i aquest al lloc web de cobertura.


## Com pots comprovar el resultat

Els dos processos han de continuar actius i curl ha de rebre la pàgina de destinació a través del servidor SOCKS5 local. Que el client s’iniciï no demostra que la connexió remota funcioni. Si la petició falla, revisa el port TCP del servidor i els camps d’identitat abans de revisar l’aplicació.

## 1. Generar les claus

Al servidor:

```sh
umbra keygen
```

Desa `x25519_private` i `mldsa_seed` només al servidor, als camps `private_key` i `mldsa_seed`. Envia `x25519_public` i `mldsa_verify` al client per un canal de confiança, per als camps `public_key` i `mldsa_verify`.

Tria a part un `short_id`: una cadena hexadecimal de longitud parella i fins a 16 caràcters. Fes servir el mateix valor als dos extrems; `keygen` no el genera.

## 2. Iniciar el servidor

Crea `server.toml`. Substitueix tots els marcadors d'identitat i `cover.example` a `dest` i `server_names` per un lloc TLS 1.3 accessible. Limita la lectura del fitxer a l'usuari del servei i als administradors.

```toml
listen = "0.0.0.0:443"
private_key = "<X25519_PRIVATE_BASE64>"
short_ids = ["<SHORT_ID_HEX>"]
dest = "cover.example:443"
server_names = ["cover.example"]
max_time_diff = "120s"
mldsa_seed = "<MLDSA_SEED_BASE64>"
```

```sh
umbra server -c server.toml
```

Umbra comprova el lloc en arrencar. Confirma que s'inicia correctament i permet el port TCP configurat al tallafoc.

## 3. Iniciar el client

Crea `client.toml`. Canvia `198.51.100.10:443` per l'adreça real i omple les claus, el `short_id` i el nom del lloc corresponents.

```toml
server = "198.51.100.10:443"
transport = "tcp"
public_key = "<X25519_PUBLIC_BASE64>"
short_id = "<SHORT_ID_HEX>"
server_name = "cover.example"
fingerprint = "chrome-latest"
mldsa_verify = "<MLDSA_VERIFY_BASE64>"
socks_listen = "127.0.0.1:1080"
```

Mantén `127.0.0.1:1080` perquè l'entrada sense contrasenya només estigui disponible en aquest dispositiu.

```sh
umbra client -c client.toml
```

## 4. Provar una petició

Des d'un altre terminal:

```sh
curl --socks5-hostname 127.0.0.1:1080 https://example.com/
```

Quan rebis resposta, configura SOCKS5 a l'aplicació amb adreça `127.0.0.1` i port `1080`. `--socks5-hostname` envia el nom de destinació al servidor intermediari. Atura els processos en primer pla amb `Ctrl-C`. Comprova TCP abans d'afegir QUIC.
