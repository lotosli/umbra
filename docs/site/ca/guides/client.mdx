Umbra ofereix un punt d'accés SOCKS5 local. Connecta-hi una aplicació directament o deixa que el client habitual gestioni les regles i hi enviï les peticions seleccionades.


## Com pots comprovar el resultat

Executa primer l’ordre curl a l’ordinador client i configura després SOCKS5 en una aplicació. Afegeix el client de regles quan funcionin totes dues proves. Obrir una pàgina per TCP no verifica UDP; prova per separat una aplicació que utilitzi UDP.

## 1. Iniciar Umbra

Prepara el servidor i substitueix els valors de `client.toml`:

```toml
server = "198.51.100.10:443"
transport = "tcp"
public_key = "<X25519_PUBLIC_BASE64>"
short_id = "<SHORT_ID_HEX>"
server_name = "cover.example"
fingerprint = "chrome-latest"
mldsa_verify = "<MLDSA_VERIFY_BASE64>"
socks_listen = "127.0.0.1:1080"
```

`server` és l'adreça d'Umbra; `server_name`, un domini de cobertura permès.

```sh
umbra client -c client.toml
```

Mantén `127.0.0.1:1080`: no es demana usuari ni contrasenya.

## 2. Connectar una aplicació

Tria SOCKS5, adreça `127.0.0.1`, port `1080`, sense credencials. L'aplicació ha d'arribar a aquesta interfície local; revisa l'aïllament de xarxa dels contenidors.

```sh
curl --proxy socks5h://127.0.0.1:1080 https://example.com/
```

`socks5h` delega el nom de domini al servidor intermediari. Les altres aplicacions controlen DNS amb els seus ajustos.

## 3. Afegir un node al client de regles

Afegeix aquesta entrada a `proxies`, inclou-la en un grup i selecciona-la:

```yaml
proxies:
  - name: Umbra Local
    type: socks5
    server: 127.0.0.1
    port: 1080
    udp: true
```

Conserva els altres nodes i regles. Envia directament l'adreça del servidor Umbra per evitar un bucle per `Umbra Local`. Configura el servidor intermediari del sistema o TUN al client habitual. Aquesta connexió utilitza SOCKS5; l'extrem remot necessita Umbra. Les subscripcions d'altres protocols continuen amb els clients compatibles.

## 4. Vision per a TCP i QUIC per a UDP

Combina aquest fragment amb la configuració completa:

```toml
transport = "tcp"
udp_transport = "quic"
mux = false
```

Activa `listen` i `udp_listen`, obre els dos protocols i tria un lloc amb QUIC. `udp: true` permet peticions UDP; SOCKS negocia l'adreça del relé, sense exigir UDP 1080.

Prova primer SOCKS5 directament, després les regles i finalment UDP. Si UDP no està disponible, canvia la configuració manualment: no hi ha canvi automàtic entre TCP i QUIC.
