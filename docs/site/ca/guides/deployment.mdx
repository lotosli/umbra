Valida una connexió en primer pla abans de crear el servei. Al Linux, systemd gestiona el procés i journald recull els registres.


## Com pots comprovar el resultat

Després del desplegament, executa l’ordre curl de la guia d’inici des d’un altre client i comprova que reps una pàgina. Reinicia el servei i repeteix la prova. Així verifiques l’accés remot, la lectura de la configuració i la recuperació després del reinici.

## Preparar fitxers i usuari

Crea l'usuari `umbra`, instal·la el programa a `/usr/local/bin/umbra` i la configuració a `/etc/umbra/server.toml`. Només l'usuari del servei i els administradors l'han de poder llegir. Adapta usuari i camins absoluts a la instal·lació.

## Configurar la xarxa

Obre el port TCP de `listen`; amb QUIC, configura `udp_listen` i obre UDP. Si una entrada de capa 4 ocupa el port públic, vincula Umbra a la interfície local i reenvia TCP/QUIC de manera transparent. Mantén privats els ports interns. Cal reenviament compatible amb aquests transports, més enllà d'una configuració HTTP convencional.

## Crear el servei

Desa a `/etc/systemd/system/umbra-server.service`:

```ini
[Unit]
Description=Umbra Server
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=umbra
ExecStart=/usr/local/bin/umbra server -c /etc/umbra/server.toml
AmbientCapabilities=CAP_NET_BIND_SERVICE
NoNewPrivileges=true
Restart=on-failure
RestartSec=5
LimitNOFILE=65535

[Install]
WantedBy=multi-user.target
```

`CAP_NET_BIND_SERVICE` permet utilitzar ports baixos com el 443. Comprova usuari, camins i permisos abans d'activar-lo.

## Iniciar i consultar registres

```sh
sudo systemctl daemon-reload
sudo systemctl enable --now umbra-server
sudo journalctl -u umbra-server -f
```

Prova després una petició des del client.

## Recursos i manteniment

L'optimització actual pressuposa almenys 1 GiB de RAM al servidor. Reserva memòria per al sistema, els buffers del nucli i els altres serveis. Els diagnòstics estan desactivats per defecte; activa'ls per investigar problemes. Reinicia després de modificar la configuració i conserva la versió anterior per poder tornar enrere.
