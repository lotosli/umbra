El servidor autentica els clients Umbra i connecta amb les destinacions de les aplicacions. La resta de connexions es reenvien al lloc de `dest`.

## Triar el lloc

Comprova que el servidor accedeix a un lloc TLS 1.3 real. Fes servir el seu domini a `server_names` i a `server_name` del client. Per a QUIC, el lloc també ha d'oferir QUIC/HTTP/3 accessible.

## Crear la configuració

Executa `umbra keygen` i tria un `short_id` seguint l'inici ràpid. Desa aquest model a `server.toml`, substituint els marcadors i `cover.example`:

```toml
listen = "0.0.0.0:443"
private_key = "<X25519_PRIVATE_BASE64>"
short_ids = ["<SHORT_ID_HEX>"]
dest = "cover.example:443"
server_names = ["cover.example"]
max_time_diff = "120s"
mldsa_seed = "<MLDSA_SEED_BASE64>"
```

`listen` defineix l'escolta TCP. Protegeix aquest fitxer: conté la clau privada i la llavor de signatura.

## Iniciar i comprovar

```sh
umbra server -c server.toml
```

Si falla la comprovació inicial, revisa destinació, domini i connectivitat. `prebuild = false` només desactiva les actualitzacions periòdiques; la comprovació inicial es manté. Revisa port i tallafoc i prova un client configurat. És normal que un navegador o una sonda TLS sense autenticar rebin el certificat del lloc de cobertura.

## Activar QUIC si cal

Afegeix `udp_listen = "0.0.0.0:443"` a la configuració completa. TCP i UDP poden compartir número de port. Permet UDP i comprova el servei QUIC del lloc. Configura el servei en segon pla quan hagis validat el funcionament en primer pla.
