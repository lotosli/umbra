Llegeix les notes, anota les versions instal·lades i desa configuracions i programes que funcionin. Planifica actualitzacions compatibles als dos extrems.

## Passar a 1.0.0-alpha

Aquesta versió millora el xifratge, la planificació de connexions compartides i la recepció QUIC. El mux adaptatiu ajusta finestres segons consum i temps d'anada i tornada, dins del pressupost de memòria. Actualitza els dos extrems per utilitzar-lo.

```toml
[performance]
adaptive_mux = true
quic_congestion = "bbr"
```

`adaptive_mux = false` selecciona el mux anterior. `mux = false` continua triant Vision dedicat; `udp_transport` es configura per separat.

## Des de versions anteriors

La versió 0.0.8 va corregir l'ordre de les parts de clau i dels secrets compartits X25519MLKEM768; cal actualitzar tots dos extrems. Revisa també les notes intermèdies. Si no cal renovar-los, conserva claus, `short_id` i noms de lloc.

## Verificar l'actualització

Comprova els programes en execució, una petició HTTPS per SOCKS5, UDP si està configurat i la recuperació després de reiniciar. Compara rendiment amb la mateixa ruta i càrrega. BBR de QUIC es gestiona a part del control de congestió TCP del sistema. Per tornar enrere, respecta la compatibilitat dels dos extrems.
