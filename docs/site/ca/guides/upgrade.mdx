## Visió general

La versió de les fonts és 1.0.0-alpha. Llegeix les notes de la publicació triada abans de substituir binaris. Registra totes dues versions, desa una còpia protegida de la configuració i conserva un executable funcional. Els canvis de format demanen coordinar client i servidor; que el lloc publiqui una versió nova no demostra que la instal·lació remota ja l’executi.

## Detalls

La versió 0.0.8 va corregir l’ordre de les parts i del secret compartit X25519MLKEM768. L’ordre invertit anterior ja no s’admet: actualitza tots dos extrems. L’alpha afegeix contextos TLS accelerats reutilitzables, planificació mux per fluxos preparats i recepció QUIC per lots. Els clients nous habiliten adaptive_mux=true per defecte i necessiten un servidor compatible. false selecciona explícitament el mux antic, sense repetir automàticament dades d’aplicació.

### Taula de rendiment opcional

```toml
[performance]
adaptive_mux = true
quic_congestion = "bbr"
```


## Verificació i límits

Les claus d’identitat, els short IDs i el SNI es poden conservar si la publicació no n’exigeix la rotació. mux=false manté Vision i udp_transport continua independent. Comprova TCP, UDP si està configurat, i l’aturada i reinici. Compara rendiments en recorreguts equivalents. BBR de Quinn afecta QUIC separadament del control TCP de Linux i no promet cap augment de velocitat.
