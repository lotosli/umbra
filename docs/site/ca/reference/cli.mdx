`server` inicia el servidor, `client` l'entrada SOCKS5 local i `keygen` genera claus.

## Consultar l'ajuda

```sh
umbra --help
umbra server --help
umbra client --help
umbra keygen
```

Consulta `--help` a la versió instal·lada.

## Carregar i substituir configuració

`-c` o `--config` carrega TOML. Les opcions indicades substitueixen els camps; els altres es conserven. Les llistes d'identificadors i noms del servidor se separen amb comes. `--mux` i `--prebuild` necessiten `true` o `false`. El rendiment es configura a `[performance]`.

## Opcions del servidor

| Ordre / opció | Funció |
|---|---|
| `-c, --config` | `server.toml` |
| `--listen` | Adreça numèrica d’escolta TCP |
| `--udp-listen` | Substituir l’adreça d’escolta QUIC UDP |
| `--private-key` | Clau privada X25519, base64, exactament 32 bytes |
| `--short-ids` | Llista no buida d’ID hexadecimals de 0–8 bytes |
| `--dest` | Destinació real de retorn, host:port |
| `--server-names` | Llista no buida de SNI admesos |
| `--max-time-diff` | Desfasament permès, almenys un segon |
| `--mldsa-seed` | Llavor ML-DSA, base64, exactament 32 bytes |
| `--prebuild` | Actualització periòdica; comprovació inicial obligatòria |
| `--padding-scheme` | Política de farciment intern |
| `--tcp-evasion` | Escriptures ordenades de ClientHello |

## Opcions del client

| Ordre / opció | Funció |
|---|---|
| `-c, --config` | `client.toml` |
| `--server` | Servidor Umbra, host:port |
| `--transport` | Transport principal: tcp o quic |
| `--udp-transport` | Substituir el transport UDP: tcp o quic |
| `--public-key` | Identitat pública X25519, 32 bytes descodificats |
| `--short-id` | Un short ID admès pel servidor |
| `--server-name` | SNI admès pel servidor |
| `--fingerprint` | Nom del perfil d’empremta integrat |
| `--mldsa-verify` | Clau de verificació ML-DSA, base64 no buit |
| `--socks-listen` | Escolta SOCKS5 local, sense autenticació |
| `--spider-path` | Camí del lloc real; comença per /, sense CR/LF |
| `--mux` | Mux xifrat; false tria TCP/Vision dedicat |
| `--padding-scheme` | Política de farciment intern |
| `--tcp-evasion` | Escriptures ordenades de ClientHello |

## Generar claus

`umbra keygen` no necessita opcions addicionals i retorna `x25519_private`, `x25519_public`, `mldsa_seed` i `mldsa_verify` en Base64. Distribueix-los segons l'inici ràpid. La sortida conté secrets: desa-la en un fitxer protegit i evita arguments que quedin a l'historial o a la llista de processos.
