Parteix de la xarxa, del manteniment que vols assumir i de les aplicacions. Umbra reuneix cobertura web, TCP/Vision, QUIC i SOCKS5. Es compara Umbra 1.0.0-alpha; Xray es refereix a VLESS + REALITY + Vision per TCP.


Contingut revisat：2026-09-18.

## Desplegament i transport

| Solució | Característiques | Desplegament | TCP i UDP |
| --- | --- | --- | --- |
| Umbra | Cobertura web i una entrada local | Instal·la la mateixa versió d’Umbra als dos extrems i inicia-la des del terminal. QUIC requereix un port UDP obert i un web de cobertura compatible amb QUIC. | Mux TCP o Vision; QUIC separat per a UDP |
| Xray + VLESS + REALITY + Vision | REALITY i Vision per TCP | Fes servir el mateix identificador d’usuari als dos extrems. Introdueix al client els paràmetres d’identitat REALITY del servidor i estableix flow a xtls-rprx-vision. | Exterior TCP aquí; UDP segons flow i client |
| VMess AEAD | Protocol xifrat amb transports a triar | Fes coincidir l’identificador d’usuari i el transport. Amb WebSocket, utilitza el mateix camí; si actives TLS, configura el domini i el certificat. | Peticions TCP/UDP; transport segons configuració |
| Trojan | TLS amb retorn a un lloc | Configura el domini del servidor, un certificat vàlid i una contrasenya; introdueix la mateixa contrasenya al client. Trojan estàndard també transporta les peticions UDP dins d’una connexió TCP. | TCP i UDP dins de TLS/TCP |
| Shadowsocks AEAD / 2022 | Intermediari xifrat amb claus | Utilitza el mateix mètode de xifratge i la mateixa clau als dos extrems; obre el port UDP si cal. Configura els complements addicionals seguint-ne les instruccions. | TCP/UDP natius; verificar cada connector |
| Hysteria 2 | QUIC; lloc HTTP/3 abans d’autenticar | Obre el port UDP del servidor i configura el certificat TLS i l’autenticació. Si la xarxa bloqueja UDP, tria un altre mètode de connexió. | TCP en fluxos fiables; UDP en datagrames no fiables |

## Què simplifica Umbra

Amb `transport = "tcp"`, `udp_transport = "quic"` i `mux = false`, una entrada local porta TCP per Vision i UDP per QUIC. N'hi ha prou amb un procés a cada extrem. Les claus i el certificat temporal eviten sol·licitar i renovar un certificat públic per al node. Mantén les claus i un lloc real accessible, amb QUIC si l'utilitzes.

SOCKS5 permet conservar aplicacions i regles. Mux redueix obertures repetides; Vision redueix xifratge extern per a TLS 1.3 apte.

## Segons l'entorn

Amb Xray/REALITY, compara rutes, clients i manteniment amb l'entrada dual d'Umbra. Amb VMess, revisa el transport abans de migrar. Trojan ofereix desplegament TLS convencional; Shadowsocks, un intermediari xifrat basat en claus i connectors segons les necessitats. Per a QUIC, compara Hysteria 2 amb les teves aplicacions UDP. Umbra és una CLI Alpha: considera també interfície gràfica, mòbil i subscripcions si et calen.

## Una diferència important per a UDP

Hysteria 2 utilitza datagrames no fiables. Umbra fa servir fluxos QUIC fiables per a les associacions UDP: les dades perdudes poden retardar les següents. Compara latència i pèrdues en trucades, jocs i altres usos en temps real.

## Més informació

L'arquitectura explica el recorregut i el model de seguretat els perfils i la negociació criptogràfica. Geneva DSL, 0-RTT i preconnexió de reserva no estan disponibles. Compara velocitat i estabilitat amb la mateixa càrrega i ruta.
