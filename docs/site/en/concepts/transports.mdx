Your app makes TCP or UDP requests. Umbra chooses how to carry them to the server: `transport` controls TCP requests; `udp_transport` may select a separate UDP path. Without an override, both use `transport`.

## Where to start

Use TCP for a first connection or when UDP is unavailable. Enable mux to reuse connections across requests, or disable it for dedicated Vision. Try QUIC when UDP is reachable, including networks where TCP suffers injected resets. To combine paths, use TCP with `udp_transport = "quic"`.

Test reachability first, then compare the same app's latency, stability and throughput. Modes are selected through configuration.

## TCP connection reuse

```toml
transport = "tcp"
mux = true
```

Requests share encrypted connections, reducing repeated setup. Adaptive windows follow consumption and round-trip time within memory budgets. A loss on the shared TCP connection can make its requests wait together. Adaptive mux requires compatible versions at both ends.

## Dedicated TCP / Vision

```toml
transport = "tcp"
mux = false
```

Each request gets its own connection. After authenticated negotiation, eligible TLS 1.3 records can be forwarded without further outer encryption or framing. Other traffic stays encrypted. Keep application HTTPS enabled. Forwarding currently uses userspace I/O; throughput depends on the device and network.

## QUIC

```toml
transport = "quic"
```

QUIC runs over UDP. Enable `udp_listen`, open the firewall port and use a reachable QUIC cover website. Separate QUIC streams can recover losses independently, while each reliable stream delivers in order. Umbra also carries UDP associations in reliable QUIC streams, so a loss can delay subsequent data in that stream.

The default controller is Quinn BBR; `cubic` and `new-reno` are also available. It controls this endpoint's outgoing QUIC traffic separately from OS TCP settings.

## Two paths, one local proxy

Client:

```toml
transport = "tcp"
udp_transport = "quic"
mux = false
socks_listen = "127.0.0.1:1080"
```

Server:

```toml
listen = "0.0.0.0:443"
udp_listen = "0.0.0.0:443"
```

Merge these into the full identity and destination configuration. Apps keep one SOCKS5 endpoint. A Clash node's `udp: true` enables UDP; TCP follows `transport`. If network conditions change, update the settings manually: automatic TCP/QUIC failover is not available.

## Padding and handshake writes

Default padding adds random-length data early in a connection, then less frequently, to soften fixed length patterns at a bandwidth cost. `tcp_evasion = "segment"` splits ClientHello into ordered application writes; the OS determines actual packet boundaries. Test `off` for compatibility issues. Geneva DSL is not supported. See the performance reference for parameters.
