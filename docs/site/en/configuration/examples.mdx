Merge these fragments into a complete configuration after setting addresses, keys and the cover website in the quick start.

## Share TCP connections

```toml
transport = "tcp"
mux = true
```

Reuse connections across requests. Adaptive flow control is enabled by default and needs a compatible server.

## Dedicated TCP / Vision

```toml
transport = "tcp"
mux = false
```

Vision forwards eligible encrypted TLS 1.3 records after authenticated negotiation, reducing repeated encryption. Other traffic stays on the encrypted channel. No extra Vision switch is needed.

## Vision for TCP, QUIC for UDP

Client:

```toml
transport = "tcp"
udp_transport = "quic"
mux = false
socks_listen = "127.0.0.1:1080"
```

Server:

```toml
listen = "0.0.0.0:443"
udp_listen = "0.0.0.0:443"
```

Allow both firewall protocols and choose a reachable QUIC/HTTP/3 cover website. One client and one server handle both paths.

## QUIC for both request types

```toml
transport = "quic"
```

Omit `udp_transport` so UDP inherits QUIC. Remove an existing override or change it to `quic`.

## A local node for Clash-compatible clients

```yaml
proxies:
  - name: Umbra
    type: socks5
    server: 127.0.0.1
    port: 1080
    udp: true
```

Add it to the existing node list and group. `udp: true` enables UDP requests; TCP still follows `transport`. Route the Umbra server directly to avoid a proxy loop. Change one mode at a time and test TCP and UDP separately before tuning performance options.
