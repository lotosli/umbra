Use TOML for the server configuration. For an initial installation, follow the server setup guide.

## Minimal configuration

Replace identity placeholders and `cover.example`:

```toml
listen = "0.0.0.0:443"
private_key = "<X25519_PRIVATE_BASE64>"
short_ids = ["<SHORT_ID_HEX>"]
dest = "cover.example:443"
server_names = ["cover.example"]
max_time_diff = "120s"
mldsa_seed = "<MLDSA_SEED_BASE64>"
```

## Fields

| Field | Default / requirement | Meaning |
|---|---|---|
| `listen` | Required | TCP socket bind address |
| `udp_listen` | `—` | Optional QUIC UDP socket; omit to disable |
| `private_key` | Required | X25519 private key, base64, exactly 32 bytes |
| `short_ids` | Required | Nonempty list of hex IDs, each 0–8 bytes |
| `dest` | Required | Real fallback destination, host:port |
| `server_names` | Required | Nonempty accepted SNI list |
| `max_time_diff` | Required | Allowed timestamp skew, at least 1 second |
| `mldsa_seed` | Required | ML-DSA signing seed, base64, exactly 32 bytes |
| `prebuild` | `true` | Periodic destination refresh; startup probe always runs |
| `padding_scheme` | `"default"` | Inner padding policy |
| `tcp_evasion` | `"segment"` | Ordered ClientHello write policy |

Place performance options in a separate `[performance]` table.

## Addresses and website names

`listen` and `udp_listen` require numeric IP addresses with ports, such as `0.0.0.0:443` or `[::]:443`. `dest` accepts a hostname and port. `server_names` needs at least one name satisfying the parser's length and ASCII rules, without whitespace. Use names matching the real website; the client selects one of them.

## Keys and short IDs

`private_key` and `mldsa_seed` are Base64 values that each decode to 32 bytes. Use the corresponding `keygen` outputs. `short_ids` needs at least one entry; each is an even-length hexadecimal string of at most 16 characters. The parser also accepts an empty string. The client value must match an entry.

## Time and site refresh

`max_time_diff` accepts `ms`, `s`, `m`, `h`, or seconds without a suffix; the resulting duration must be at least one second. Check system clocks before changing the tolerance. A destination probe runs on every startup. `prebuild` controls subsequent periodic refreshes and defaults to true.

## Command-line overrides

Provided CLI values override matching file fields; omitted values remain unchanged. Required values, types and unknown fields are checked after merging. CLI names use hyphens, such as `--udp-listen`; TOML uses underscores. Keep secrets in a protected file so they stay out of shell history and process arguments.
