The same Umbra binary runs in client or server mode. Choose the same release for both ends and the correct operating system and CPU architecture for each device.

## Download a binary

Open the [GitHub releases](https://github.com/lotosli/umbra/releases) and choose a file from the release assets. The table helps identify build targets; available downloads depend on that release.

| Platform | Architecture | Artifact target |
|---|---|---|
| macOS | Apple Silicon | `umbra-aarch64-apple-darwin` |
| macOS | Intel | `umbra-x86_64-apple-darwin` |
| Linux | x86_64 | `umbra-x86_64-unknown-linux-gnu` |
| Linux | aarch64 | `umbra-aarch64-unknown-linux-gnu` |
| Windows | x86_64 | `umbra-x86_64-pc-windows-msvc.exe` |

## Install on your device

On macOS or Linux, extract the archive if needed and make the downloaded binary executable. You can rename it to `umbra` and place it in a directory on `PATH`. On Windows, extract if needed and run the `.exe` from a terminal, or add its directory to `PATH`.

Read the release notes and check the file against any verification information provided with the release.

## Build from source

Use the repository's pinned Rust 1.96.1 toolchain:

```sh
git clone https://github.com/lotosli/umbra.git
cd umbra
cargo build --release
./target/release/umbra --help
```

The binary is under `target/release`; Windows adds the `.exe` suffix.

## Check the installation

Run `umbra --help`, using the full path if necessary. It should list `server`, `client` and `keygen`. Next, generate keys and configure both ends. Set up background operation later using the deployment guide.
