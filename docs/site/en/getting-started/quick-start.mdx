Start with TCP. Install the same Umbra version on your server and client device. The client must reach the server, and the server must reach the real cover website.


## How to check the result

Both processes should stay running, and curl should return the target page through the local SOCKS5 proxy. A running client alone does not prove that the remote connection works. If the request fails, check the server’s TCP port and the identity fields on both ends before investigating app settings.

## 1. Generate keys

Run on the server:

```sh
umbra keygen
```

Keep `x25519_private` and `mldsa_seed` on the server, as `private_key` and `mldsa_seed`. Send `x25519_public` and `mldsa_verify` to the client through a trusted channel, as `public_key` and `mldsa_verify`.

Choose a separate `short_id`: an even-length hexadecimal string of up to 16 characters. Use the same value at both ends. `keygen` does not generate it.

## 2. Start the server

Create `server.toml`. Replace every identity placeholder and replace `cover.example` in both `dest` and `server_names` with a reachable TLS 1.3 website. Restrict access to the configuration file to the service user and administrators.

```toml
listen = "0.0.0.0:443"
private_key = "<X25519_PRIVATE_BASE64>"
short_ids = ["<SHORT_ID_HEX>"]
dest = "cover.example:443"
server_names = ["cover.example"]
max_time_diff = "120s"
mldsa_seed = "<MLDSA_SEED_BASE64>"
```

```sh
umbra server -c server.toml
```

Umbra probes the cover website at startup. Confirm startup succeeds and allow the configured TCP port through the firewall.

## 3. Start the client

Create `client.toml`. Replace `198.51.100.10:443` with the actual server address and enter the matching keys, `short_id` and website name.

```toml
server = "198.51.100.10:443"
transport = "tcp"
public_key = "<X25519_PUBLIC_BASE64>"
short_id = "<SHORT_ID_HEX>"
server_name = "cover.example"
fingerprint = "chrome-latest"
mldsa_verify = "<MLDSA_VERIFY_BASE64>"
socks_listen = "127.0.0.1:1080"
```

Keep `127.0.0.1:1080` so the local proxy, which has no password authentication, is available only on this device.

```sh
umbra client -c client.toml
```

## 4. Try a request

From another terminal:

```sh
curl --socks5-hostname 127.0.0.1:1080 https://example.com/
```

Once you receive a response, configure your app to use SOCKS5 at `127.0.0.1`, port `1080`. The `--socks5-hostname` option passes the destination hostname to the proxy. Stop foreground processes with `Ctrl-C`. Get TCP working before adding QUIC; use troubleshooting if a step fails.
