Read the target release notes, record both installed versions, back up configuration and keep the working binaries. Schedule compatible updates for both ends.

## Upgrade to 1.0.0-alpha

This release improves encryption processing, shared-connection scheduling and QUIC reception. Adaptive mux adjusts receive windows using consumption and round-trip time, within the memory budget. Update both ends to use it.

```toml
[performance]
adaptive_mux = true
quic_congestion = "bbr"
```

Set `adaptive_mux = false` to select legacy mux explicitly. This controls TCP multiplexing; `mux = false` still selects dedicated Vision, and `udp_transport` still selects the UDP path independently.

## Coming from an older release

Version 0.0.8 corrected X25519MLKEM768 key-share and shared-secret ordering. Both ends need updating across that change. Check intermediate release notes for other protocol or configuration changes. Unless rotation is required, keep existing keys, `short_id` and website names.

## Verify after updating

1. Confirm both processes use the newly installed binaries.
2. Make an HTTPS request through local SOCKS5.
3. Test UDP if configured.
4. Restart and check that connections recover.
5. Compare performance using the same path and workload.

QUIC defaults to BBR, configured separately from OS TCP congestion control. If needed, roll back both ends according to the releases' compatibility requirements.
