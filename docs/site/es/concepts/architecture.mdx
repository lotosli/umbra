Umbra combina proxy local, autenticación y transporte remoto. Los crates de Rust separan el análisis del protocolo, la criptografía y la gestión de conexiones para probarlos individualmente.

## Recorrido de una solicitud

La aplicación usa SOCKS5 local. El cliente establece TCP o QUIC y verifica la identidad. El servidor conecta con el destino y retransmite datos. Las conexiones sin autenticar van al sitio de cobertura. `server`, `client` y `keygen` inician los extremos y generan claves.

## Componentes

`umbra-proto` define formatos y direcciones; `umbra-crypto`, intercambio de claves, firmas, derivación y cifrado. `umbra-fingerprint` contiene perfiles y herramientas JA3/JA4; `umbra-tls` procesa TLS 1.3.

`umbra-reality` gestiona autenticación, repetición y preparación del sitio; `umbra-inner`, multiplexación, relleno y Vision; `umbra-transport`, TCP y QUIC. `umbra-core` coordina configuración, SOCKS5, distribución y recursos. `umbra` es la CLI.

## Dependencias principales

```text
umbra CLI
    ↓
umbra-core
    ↓
umbra-reality · umbra-inner · umbra-transport
    ↓
umbra-tls
    ↓
umbra-crypto · umbra-fingerprint
    ↓
umbra-proto
```

`umbra-testkit` ofrece pruebas locales; `xtask` ejecuta comprobaciones y compilaciones de publicación. Consulta guías y código actuales para las funciones disponibles.

## El sitio web y tus conexiones

La web ofrece descargas, documentación y notas de versión. Los programas usan configuración local; la web no administra tus conexiones ni almacena su configuración.
