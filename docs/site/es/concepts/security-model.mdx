Umbra verifica identidades, protege el transporte y reenvía conexiones sin autenticar a una web real. Tú gestionas claves, dispositivos y servidor.

## Autenticación y cobertura

El servidor verifica la autenticación antes de responder. El cliente comprueba la vinculación del certificado temporal con la identidad esperada. Otras conexiones van al sitio de cobertura. Una caché con límites de tamaño y duración detecta repeticiones. La criptografía usa comparaciones en tiempo constante y almacenamiento y borrado específicos para secretos.

## Claves y acceso local

Guarda `private_key` y `mldsa_seed` en el servidor. Comparte la configuración por un canal de confianza, limita permisos y elimina credenciales de registros públicos. SOCKS5 no tiene contraseña: escucha en `127.0.0.1:1080`. Configura controles de acceso antes de abrirlo a otros dispositivos.

## Cifrado de las aplicaciones

Sigue usando HTTPS. Vision reenvía datos ya protegidos cuando corresponde. La seguridad de dispositivos, cuentas y destinos requiere sus propias medidas.

## Alcance de la cobertura

Las visitas y sondas no autenticadas reciben respuestas del sitio. Direcciones, horarios y volúmenes siguen siendo observables, y la IP puede bloquearse. Umbra es un proxy autogestionado, sin la separación de identidad de una red anónima de varios saltos.

## Perfiles de navegador

`chrome-latest` usa Chrome 150; el repositorio también incluye capturas Chrome 153 TCP/QUIC. Perfiles, capturas y JA3/JA4 verifican características concretas; no se ha verificado equivalencia completa con el comportamiento de red del Chrome actual.

## Algoritmos poscuánticos

ML-DSA-65 vincula la clave pública del certificado temporal. X25519 + ML-KEM-768 solo se usa si se negocia. La sonda de destino de la CLI usa ring, sin ML-KEM, y el servidor sigue el grupo observado. Evalúa la negociación real del despliegue.

## Versión y avisos de seguridad

La versión **1.0.0-alpha** no tiene evidencia pública de una auditoría independiente terminada. Para usos sensibles, revisa implementación, versiones y despliegue. Consulta [GitHub Security](https://github.com/lotosli/umbra/security) antes de informar de una vulnerabilidad. No publiques detalles explotables, credenciales ni infraestructura sensible.
