`transport` elige el transporte TCP. `udp_transport` puede dar una ruta distinta a UDP; si se omite, hereda `transport`.

## Por dónde empezar

Usa TCP para la primera conexión o si UDP no está disponible. Activa mux para reutilizar conexiones o desactívalo para Vision dedicado. Prueba QUIC cuando UDP funcione, especialmente si TCP sufre reinicios inyectados. Combina rutas con TCP y `udp_transport = "quic"`. Comprueba primero conectividad y luego latencia, estabilidad y caudal con la misma aplicación.

## Reutilizar conexiones TCP

```toml
transport = "tcp"
mux = true
```

Las solicitudes comparten conexiones cifradas. Las ventanas adaptativas siguen el consumo y el tiempo de ida y vuelta dentro de los presupuestos. Una pérdida TCP puede hacer esperar a las solicitudes que comparten conexión. Usa versiones compatibles.

## TCP / Vision dedicado

```toml
transport = "tcp"
mux = false
```

Cada solicitud tiene su conexión. Tras negociar la autenticación, los registros TLS 1.3 aptos se reenvían sin cifrado externo ni encapsulación adicional. El resto permanece cifrado. Mantén HTTPS en las aplicaciones. El reenvío funciona en espacio de usuario; el rendimiento depende del dispositivo y la red.

## QUIC

```toml
transport = "quic"
```

QUIC usa UDP. Activa `udp_listen`, abre el puerto y usa un sitio QUIC accesible. Los flujos separados recuperan pérdidas independientemente; cada flujo fiable entrega en orden. Umbra también transporta asociaciones UDP en flujos QUIC fiables, por lo que una pérdida puede retrasar los datos siguientes.

Quinn BBR es el predeterminado; también hay `cubic` y `new-reno`. Controlan el envío QUIC local, por separado de TCP del sistema.

## Dos rutas, un proxy

Cliente:

```toml
transport = "tcp"
udp_transport = "quic"
mux = false
socks_listen = "127.0.0.1:1080"
```

Servidor:

```toml
listen = "0.0.0.0:443"
udp_listen = "0.0.0.0:443"
```

Conserva los demás campos de la configuración completa. Las aplicaciones usan un SOCKS5. `udp: true` permite UDP en Clash; TCP sigue `transport`. Ajusta la configuración si cambia la red: la conmutación TCP/QUIC es manual.

## Relleno y escritura del saludo

El relleno añade datos de longitud aleatoria al principio y después con menor frecuencia para suavizar patrones de longitud, consumiendo ancho de banda. `tcp_evasion = "segment"` divide ClientHello en escrituras ordenadas; el sistema determina los paquetes reales. Prueba `off` ante problemas de compatibilidad. Geneva DSL no está disponible.
