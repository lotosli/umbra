El TOML del cliente define el extremo remoto y la entrada SOCKS5 local.

## Configuración mínima

Sustituye dirección, dominio e identidad:

```toml
server = "198.51.100.10:443"
transport = "tcp"
public_key = "<X25519_PUBLIC_BASE64>"
short_id = "<SHORT_ID_HEX>"
server_name = "cover.example"
fingerprint = "chrome-latest"
mldsa_verify = "<MLDSA_VERIFY_BASE64>"
socks_listen = "127.0.0.1:1080"
```

## Campos

| Campo | Valor predeterminado / requisito | Significado |
|---|---|---|
| `server` | Obligatorio | Servidor Umbra, host:puerto |
| `transport` | Obligatorio | Transporte principal: tcp o quic |
| `udp_transport` | `transport` | Transporte UDP; hereda transport si se omite |
| `public_key` | Obligatorio | Identidad pública X25519, 32 bytes decodificados |
| `short_id` | Obligatorio | Un short ID admitido por el servidor |
| `server_name` | Obligatorio | SNI admitido por el servidor |
| `fingerprint` | Obligatorio | Nombre de perfil de huella incorporado |
| `mldsa_verify` | Obligatorio | Clave de verificación ML-DSA, base64 no vacío |
| `socks_listen` | Obligatorio | Escucha SOCKS5 local, sin autenticación |
| `spider_path` | `"/"` | Ruta del sitio real; empieza por /, sin CR/LF |
| `mux` | `true` | Mux cifrado; false elige TCP/Vision dedicado |
| `padding_scheme` | `"default"` | Política de relleno interno |
| `tcp_evasion` | `"segment"` | Escrituras ordenadas de ClientHello |

## Verificar la identidad

`public_key` es la clave X25519 del servidor, de 32 bytes tras decodificar. `mldsa_verify` es la clave de verificación Base64 no vacía correspondiente. Obtén ambas por un canal de confianza. `short_id` y `server_name` deben coincidir con las listas del servidor.

## Elegir transportes

`transport` es obligatorio: `tcp` o `quic`. UDP hereda su valor final salvo que se indique `udp_transport`, que solo afecta a UDP. TCP usa `mux = true` por defecto; false selecciona Vision dedicado.

## Acceso local y perfiles

Usa `127.0.0.1:1080` en `socks_listen`, ya que no hay contraseña. `fingerprint` elige el perfil del saludo. `chrome-latest` y `chrome-150-macos` usan actualmente Chrome 150; los alias cambian con las versiones.

`spider_path` vale `/` por defecto y se usa en el comportamiento de sitio real cuando no se autentica una sesión Umbra. Debe empezar por `/` y no contener retornos de carro ni saltos de línea. La CLI sustituye campos antes de validar. El rendimiento se configura en `[performance]`; empieza con los valores predeterminados.
