Combina estos fragmentos con una configuración completa después de rellenar direcciones, claves y sitio de cobertura.

## Compartir conexiones TCP

```toml
transport = "tcp"
mux = true
```

Las solicitudes reutilizan conexiones. El control de flujo adaptativo está activo por defecto y requiere un servidor compatible.

## TCP / Vision dedicado

```toml
transport = "tcp"
mux = false
```

Tras negociar la autenticación, Vision reenvía registros TLS 1.3 aptos ya cifrados. El resto del tráfico sigue cifrado. No hace falta otra opción para Vision.

## Vision para TCP, QUIC para UDP

Cliente:

```toml
transport = "tcp"
udp_transport = "quic"
mux = false
socks_listen = "127.0.0.1:1080"
```

Servidor:

```toml
listen = "0.0.0.0:443"
udp_listen = "0.0.0.0:443"
```

Abre TCP y UDP y usa un sitio QUIC/HTTP/3 accesible. Basta un proceso en cada extremo.

## QUIC para ambos tipos de solicitud

```toml
transport = "quic"
```

Omite `udp_transport` para heredar QUIC. Elimina una opción anterior o cámbiala a `quic`.

## Nodo local para un cliente compatible con Clash

```yaml
proxies:
  - name: Umbra
    type: socks5
    server: 127.0.0.1
    port: 1080
    udp: true
```

Añádelo a la lista y al grupo existentes. `udp: true` permite UDP; TCP sigue `transport`. Envía directamente la dirección del servidor Umbra para evitar bucles. Cambia un modo cada vez y prueba TCP y UDP por separado.
