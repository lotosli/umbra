El servidor usa TOML. Para la primera instalación, sigue la guía del servidor.

## Configuración mínima

Sustituye los marcadores y `cover.example`:

```toml
listen = "0.0.0.0:443"
private_key = "<X25519_PRIVATE_BASE64>"
short_ids = ["<SHORT_ID_HEX>"]
dest = "cover.example:443"
server_names = ["cover.example"]
max_time_diff = "120s"
mldsa_seed = "<MLDSA_SEED_BASE64>"
```

## Campos

| Campo | Valor predeterminado / requisito | Significado |
|---|---|---|
| `listen` | Obligatorio | Dirección numérica de escucha TCP |
| `udp_listen` | `—` | Escucha QUIC UDP opcional; omitir para desactivar |
| `private_key` | Obligatorio | Clave privada X25519, base64, exactamente 32 bytes |
| `short_ids` | Obligatorio | Lista no vacía de ID hexadecimales de 0–8 bytes |
| `dest` | Obligatorio | Destino real de respaldo, host:puerto |
| `server_names` | Obligatorio | Lista no vacía de SNI admitidos |
| `max_time_diff` | Obligatorio | Desfase permitido, al menos un segundo |
| `mldsa_seed` | Obligatorio | Semilla ML-DSA, base64, exactamente 32 bytes |
| `prebuild` | `true` | Actualización periódica; comprobación inicial obligatoria |
| `padding_scheme` | `"default"` | Política de relleno interno |
| `tcp_evasion` | `"segment"` | Escrituras ordenadas de ClientHello |

Coloca los parámetros de rendimiento en `[performance]`.

## Direcciones y dominios

`listen` y `udp_listen` requieren IP numérica y puerto: `0.0.0.0:443` o `[::]:443`. `dest` admite un nombre de host. `server_names` necesita al menos un nombre que cumpla los límites de longitud y sintaxis ASCII, sin espacios. Usa dominios del sitio real; el cliente elige uno.

## Claves e identificadores

`private_key` y `mldsa_seed` son Base64 y se decodifican en 32 bytes cada uno. Usa las salidas de `keygen`. `short_ids` contiene al menos una cadena hexadecimal de longitud par, hasta 16 caracteres; también se acepta una cadena vacía. El valor del cliente debe coincidir.

## Hora y actualización del sitio

`max_time_diff` acepta `ms`, `s`, `m`, `h`, o segundos sin sufijo; la duración final es al menos un segundo. Revisa los relojes antes de ampliar la tolerancia. El sitio se comprueba en cada arranque; `prebuild`, activo por defecto, controla las actualizaciones posteriores.

## Opciones de línea de comandos

Las opciones proporcionadas sustituyen los campos del archivo antes de validar valores requeridos, tipos y campos desconocidos. La CLI usa guiones, como `--udp-listen`; TOML usa guiones bajos. Guarda secretos en archivos protegidos para evitar el historial y los argumentos de procesos.
