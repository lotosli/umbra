## Acordar el cambio

Las funciones siguen OpenSpec: propuesta, requisitos y escenarios, aprobación humana e implementación. La documentación debe reflejar el código actual y conservar los identificadores en los siete idiomas.

## Verificar el trabajo

Ejecuta formato, lint, pruebas, dependencias y cobertura según el cambio. La cobertura de líneas Rust debe ser al menos del 90 %. Los analizadores necesitan casos límite y de error; criptografía y huellas requieren vectores o capturas correspondientes.

```sh
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
cargo nextest run --workspace
cargo deny check
cargo xtask coverage
npx --yes @fission-ai/openspec@latest validate --all --strict
```

La web tiene controles propios en `docs/website-development.md`. Centraliza dependencias y comprueba licencias.

## Enviar para revisión

Usa Conventional Commits y explica problema, alcance y validación en la PR. Quien contribuye debe entender, revisar y probar el trabajo asistido por IA y declarar el contenido generado sustancial. Retira credenciales reales, infraestructura privada y vulnerabilidades no publicadas. Umbra usa licencia MIT.
