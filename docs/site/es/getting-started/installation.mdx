El mismo programa funciona como cliente o servidor. Usa la misma versión en ambos extremos y el archivo adecuado para el sistema y la arquitectura de cada equipo.

## Descargar

Abre las [versiones de GitHub](https://github.com/lotosli/umbra/releases). La tabla identifica los destinos de compilación; los archivos disponibles dependen de cada versión.

| Plataforma | Arquitectura | Destino de compilación |
|---|---|---|
| macOS | Apple Silicon | `umbra-aarch64-apple-darwin` |
| macOS | Intel | `umbra-x86_64-apple-darwin` |
| Linux | x86_64 | `umbra-x86_64-unknown-linux-gnu` |
| Linux | aarch64 | `umbra-aarch64-unknown-linux-gnu` |
| Windows | x86_64 | `umbra-x86_64-pc-windows-msvc.exe` |

## Instalar el programa

En macOS o Linux, descomprime el archivo si hace falta y dale permiso de ejecución al programa. Puedes renombrarlo a `umbra` y colocarlo en un directorio de `PATH`. En Windows, ejecuta el `.exe` desde una terminal o añade su carpeta a `PATH`. Lee las notas de versión y comprueba el archivo con la información de verificación que se publique.

## Compilar desde el código fuente

Usa la versión de Rust fijada en el repositorio, 1.96.1:

```sh
git clone https://github.com/lotosli/umbra.git
cd umbra
cargo build --release
./target/release/umbra --help
```

El programa queda en `target/release`, con extensión `.exe` en Windows.

## Comprobar la instalación

Ejecuta `umbra --help`, con la ruta completa si es necesario. Deben aparecer `server`, `client` y `keygen`. A continuación genera las claves y configura ambos extremos. La guía de despliegue explica cómo ejecutarlo en segundo plano.
