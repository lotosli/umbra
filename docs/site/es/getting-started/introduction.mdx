Umbra es un proxy de código abierto que alojas tú. Ejecuta el servidor en tu infraestructura y el cliente en tu dispositivo; después conecta las aplicaciones a su proxy SOCKS5 local. Tú eliges el servidor, el transporte y qué aplicaciones lo usan.


Empieza con la configuración TCP mínima si quieres gestionar tu propio servidor y conectar algunas aplicaciones a través de él. Comprueba que funciona un cliente antes de añadir tu herramienta de rutas; no necesitas ajustar todos los parámetros desde el principio.
## ¿Por qué usar Umbra?

### Un sitio web real como cobertura

Tu cliente se autentica para abrir la conexión proxy. Las demás conexiones se envían al sitio web configurado y reciben su respuesta habitual.

### Una entrada para TCP y UDP

Un solo cliente y un solo servidor pueden enviar las solicitudes TCP por TCP y las UDP por QUIC. Las aplicaciones siguen usando una única dirección SOCKS5.

### Menos trabajo repetido

La multiplexación permite reutilizar conexiones. Vision puede reenviar directamente registros TLS 1.3 ya cifrados que cumplan las condiciones necesarias, reduciendo el cifrado externo y la encapsulación.

### Conserva tus herramientas

Las aplicaciones con SOCKS5 se conectan directamente. Un cliente compatible con Clash puede mantener su interfaz y sus reglas mientras Umbra se encarga de la conexión remota. Tampoco necesitas solicitar ni renovar un certificado de una CA pública para el nodo Umbra.

## Qué necesitas

Un servidor accesible, la misma versión de Umbra en ambos extremos, un sitio TLS 1.3 real accesible desde el servidor y una aplicación o cliente con SOCKS5. Umbra funciona por línea de comandos, con licencia MIT y sin cuenta de Umbra. Tú proporcionas y mantienes el servidor. Los nodos VLESS, VMess y Trojan siguen usando sus clientes; una conexión Umbra necesita Umbra en ambos extremos.

## Empieza con una aplicación

Sigue el inicio rápido antes de añadir reglas o QUIC. Tú decides qué aplicaciones usan el proxy. La versión actual es **1.0.0-alpha**: conserva un programa y una configuración que funcionen. El proxy local no tiene contraseña; limita su escucha a `127.0.0.1:1080`. Consulta el modelo de seguridad para más detalles.
