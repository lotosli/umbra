Empieza con TCP. Instala la misma versión en el servidor y en el dispositivo cliente. El cliente debe llegar al servidor, y este al sitio web de cobertura.


## Cómo comprobar el resultado

Ambos procesos deben seguir ejecutándose y curl debe recibir la página de destino a través del proxy SOCKS5 local. Que el cliente arranque no demuestra que la conexión remota funcione. Si falla la solicitud, revisa el puerto TCP del servidor y los campos de identidad antes de revisar la aplicación.

## 1. Generar las claves

En el servidor:

```sh
umbra keygen
```

Guarda `x25519_private` y `mldsa_seed` solo en el servidor, en los campos `private_key` y `mldsa_seed`. Envía `x25519_public` y `mldsa_verify` al cliente por un canal de confianza para rellenar `public_key` y `mldsa_verify`.

Elige aparte un `short_id`: una cadena hexadecimal de longitud par y hasta 16 caracteres. Usa el mismo valor en ambos extremos; `keygen` no lo genera.

## 2. Iniciar el servidor

Crea `server.toml`. Sustituye todos los marcadores de identidad y `cover.example` en `dest` y `server_names` por un sitio TLS 1.3 accesible. Limita la lectura del archivo al usuario del servicio y a los administradores.

```toml
listen = "0.0.0.0:443"
private_key = "<X25519_PRIVATE_BASE64>"
short_ids = ["<SHORT_ID_HEX>"]
dest = "cover.example:443"
server_names = ["cover.example"]
max_time_diff = "120s"
mldsa_seed = "<MLDSA_SEED_BASE64>"
```

```sh
umbra server -c server.toml
```

Umbra comprueba el sitio al arrancar. Confirma que inicia correctamente y permite el puerto TCP configurado en el cortafuegos.

## 3. Iniciar el cliente

Crea `client.toml`. Cambia `198.51.100.10:443` por la dirección real y rellena las claves, el `short_id` y el nombre de sitio correspondientes.

```toml
server = "198.51.100.10:443"
transport = "tcp"
public_key = "<X25519_PUBLIC_BASE64>"
short_id = "<SHORT_ID_HEX>"
server_name = "cover.example"
fingerprint = "chrome-latest"
mldsa_verify = "<MLDSA_VERIFY_BASE64>"
socks_listen = "127.0.0.1:1080"
```

Mantén `127.0.0.1:1080` para que el proxy sin contraseña solo esté disponible en este dispositivo.

```sh
umbra client -c client.toml
```

## 4. Probar una solicitud

Desde otra terminal:

```sh
curl --socks5-hostname 127.0.0.1:1080 https://example.com/
```

Cuando recibas una respuesta, configura SOCKS5 en la aplicación con dirección `127.0.0.1` y puerto `1080`. `--socks5-hostname` envía el nombre de destino al proxy. Detén los procesos en primer plano con `Ctrl-C`. Comprueba TCP antes de añadir QUIC.
