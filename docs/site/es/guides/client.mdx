Umbra ofrece un proxy SOCKS5 local. Conecta una aplicación directamente o deja que tu cliente habitual gestione las reglas y envíe a Umbra las solicitudes elegidas.


## Cómo comprobar el resultado

Ejecuta primero el comando curl en el equipo cliente y configura después SOCKS5 en una aplicación. Añade el cliente de reglas cuando funcionen ambas pruebas. Abrir una página por TCP no comprueba UDP; prueba por separado una aplicación que use UDP.

## 1. Iniciar Umbra

Prepara el servidor y sustituye los valores en `client.toml`:

```toml
server = "198.51.100.10:443"
transport = "tcp"
public_key = "<X25519_PUBLIC_BASE64>"
short_id = "<SHORT_ID_HEX>"
server_name = "cover.example"
fingerprint = "chrome-latest"
mldsa_verify = "<MLDSA_VERIFY_BASE64>"
socks_listen = "127.0.0.1:1080"
```

`server` es la dirección de Umbra; `server_name`, un dominio de cobertura permitido.

```sh
umbra client -c client.toml
```

Mantén `127.0.0.1:1080`: este proxy no pide usuario ni contraseña.

## 2. Conectar una aplicación

Elige SOCKS5, dirección `127.0.0.1`, puerto `1080`, sin credenciales. La aplicación debe alcanzar esa misma interfaz local; revisa el aislamiento de red si usas contenedores.

```sh
curl --proxy socks5h://127.0.0.1:1080 https://example.com/
```

`socks5h` deja el nombre de dominio en manos del proxy. Las demás aplicaciones controlan DNS con sus propios ajustes.

## 3. Añadir un nodo al cliente de reglas

Añade esta entrada a `proxies`, inclúyela en un grupo y selecciónala:

```yaml
proxies:
  - name: Umbra Local
    type: socks5
    server: 127.0.0.1
    port: 1080
    udp: true
```

Conserva el resto de nodos y reglas. Envía directamente la dirección del servidor Umbra para evitar un bucle por `Umbra Local`. Configura el proxy del sistema o TUN en tu cliente habitual. Esta conexión usa SOCKS5; el extremo remoto necesita Umbra. Las suscripciones de otros protocolos se gestionan con sus clientes compatibles.

## 4. Vision para TCP y QUIC para UDP

Combina este fragmento con la configuración completa:

```toml
transport = "tcp"
udp_transport = "quic"
mux = false
```

Activa `listen` y `udp_listen`, abre ambos protocolos y elige un sitio con QUIC. `udp: true` permite solicitudes UDP; SOCKS negocia la dirección de retransmisión, sin exigir UDP 1080.

Prueba primero SOCKS5 directamente, después las reglas y finalmente UDP. Si UDP no está disponible, cambia la configuración manualmente: no hay conmutación automática entre TCP y QUIC.
