Valida una conexión en primer plano antes de crear el servicio. En Linux, systemd gestiona el proceso y journald recoge los registros.


## Cómo comprobar el resultado

Después del despliegue, ejecuta el comando curl del inicio rápido desde otro cliente y comprueba que recibes una página. Reinicia el servicio y repite la prueba. Así verificas el acceso remoto, la lectura de la configuración y la recuperación tras reiniciar.

## Preparar archivos y usuario

Crea el usuario `umbra`, instala el programa en `/usr/local/bin/umbra` y la configuración en `/etc/umbra/server.toml`. Solo el usuario del servicio y los administradores deben leerla. Adapta usuario y rutas absolutas a tu instalación.

## Configurar la red

Abre el puerto TCP de `listen`; con QUIC, configura `udp_listen` y abre UDP. Si una entrada de capa 4 ocupa el puerto público, enlaza Umbra a la interfaz local y reenvía TCP/QUIC de forma transparente. Mantén privados los puertos internos. Se necesita reenvío compatible con estos transportes, no una configuración HTTP convencional.

## Crear el servicio

Guarda en `/etc/systemd/system/umbra-server.service`:

```ini
[Unit]
Description=Umbra Server
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=umbra
ExecStart=/usr/local/bin/umbra server -c /etc/umbra/server.toml
AmbientCapabilities=CAP_NET_BIND_SERVICE
NoNewPrivileges=true
Restart=on-failure
RestartSec=5
LimitNOFILE=65535

[Install]
WantedBy=multi-user.target
```

`CAP_NET_BIND_SERVICE` permite usar puertos bajos como 443. Comprueba usuario, rutas y permisos antes de activarlo.

## Iniciar y consultar registros

```sh
sudo systemctl daemon-reload
sudo systemctl enable --now umbra-server
sudo journalctl -u umbra-server -f
```

Prueba después una solicitud desde el cliente.

## Recursos y mantenimiento

La optimización actual presupone al menos 1 GiB de RAM en el servidor. Reserva memoria para el sistema, los búferes del núcleo y otros servicios. Los diagnósticos vienen desactivados; actívalos al investigar un problema. Reinicia tras modificar la configuración y conserva la versión anterior para poder volver atrás.
