Lee las notas de la versión, anota las instaladas y guarda configuraciones y programas que funcionen. Planifica actualizaciones compatibles en ambos extremos.

## Pasar a 1.0.0-alpha

Esta versión mejora el cifrado, la planificación de conexiones compartidas y la recepción QUIC. El mux adaptativo ajusta ventanas según consumo y tiempo de ida y vuelta, dentro del presupuesto de memoria. Actualiza ambos extremos para usarlo.

```toml
[performance]
adaptive_mux = true
quic_congestion = "bbr"
```

`adaptive_mux = false` selecciona explícitamente el mux anterior. `mux = false` sigue eligiendo Vision dedicado; `udp_transport` se configura por separado.

## Desde versiones anteriores

La versión 0.0.8 corrigió el orden de las partes de clave y secretos compartidos X25519MLKEM768; requiere actualizar ambos extremos. Revisa también las notas intermedias. Si no hace falta rotarlos, conserva claves, `short_id` y nombres de sitio.

## Verificar la actualización

Comprueba los programas que se ejecutan, una solicitud HTTPS por SOCKS5, UDP si está configurado y la recuperación tras reiniciar. Compara rendimiento con la misma ruta y carga. BBR de QUIC se gestiona aparte del control de congestión TCP del sistema. Para volver atrás, respeta la compatibilidad de ambos extremos.
