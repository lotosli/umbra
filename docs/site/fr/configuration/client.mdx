Le fichier TOML décrit le serveur distant et le proxy SOCKS5 local.

## Configuration minimale

Remplacez l'adresse, le domaine et les valeurs d'identité :

```toml
server = "198.51.100.10:443"
transport = "tcp"
public_key = "<X25519_PUBLIC_BASE64>"
short_id = "<SHORT_ID_HEX>"
server_name = "cover.example"
fingerprint = "chrome-latest"
mldsa_verify = "<MLDSA_VERIFY_BASE64>"
socks_listen = "127.0.0.1:1080"
```

## Champs

| Champ | Valeur par défaut / exigence | Signification |
|---|---|---|
| `server` | Obligatoire | Serveur Umbra, hôte:port |
| `transport` | Obligatoire | Transport principal : tcp ou quic |
| `udp_transport` | `transport` | Transport UDP ; hérite de transport si absent |
| `public_key` | Obligatoire | Identité publique X25519, 32 octets décodés |
| `short_id` | Obligatoire | Un short ID accepté par le serveur |
| `server_name` | Obligatoire | SNI accepté par le serveur |
| `fingerprint` | Obligatoire | Nom du profil d’empreinte intégré |
| `mldsa_verify` | Obligatoire | Clé de vérification ML-DSA, base64 non vide |
| `socks_listen` | Obligatoire | Écoute SOCKS5 locale, sans authentification |
| `spider_path` | `"/"` | Chemin du site réel ; commence par /, sans CR/LF |
| `mux` | `true` | Mux chiffré ; false sélectionne TCP/Vision dédié |
| `padding_scheme` | `"default"` | Politique de remplissage interne |
| `tcp_evasion` | `"segment"` | Écritures ordonnées du ClientHello |

## Vérifier l'identité

`public_key` est la clé X25519 du serveur, soit 32 octets après décodage. `mldsa_verify` est la clé de vérification Base64 non vide correspondante. Obtenez-les par un canal de confiance. `short_id` et `server_name` doivent appartenir aux listes autorisées du serveur.

## Choisir les transports

`transport` est obligatoire : `tcp` ou `quic`. UDP reprend sa valeur finale sauf si `udp_transport` est renseigné. Cette option ne change que les requêtes UDP. TCP utilise `mux = true` par défaut ; false sélectionne Vision dédié.

## Accès local et profils

Liez `socks_listen` à `127.0.0.1:1080`, car le proxy n'a pas de mot de passe. `fingerprint` sélectionne le profil de négociation. `chrome-latest` et `chrome-150-macos` utilisent actuellement Chrome 150 ; les alias évoluent avec les versions.

`spider_path`, par défaut `/`, sert au comportement de site réel lorsque la session Umbra n'est pas authentifiée. Il commence par `/` et ne contient ni retour chariot ni saut de ligne. Les options CLI remplacent les champs avant validation. Placez les réglages de performance dans `[performance]` et commencez par les valeurs par défaut.
