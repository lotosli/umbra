Fusionnez ces fragments avec une configuration complète après avoir renseigné adresses, clés et site de couverture.

## Partager les connexions TCP

```toml
transport = "tcp"
mux = true
```

Les requêtes réutilisent les connexions. Le contrôle de flux adaptatif est actif par défaut et nécessite un serveur compatible.

## TCP / Vision dédié

```toml
transport = "tcp"
mux = false
```

Après négociation authentifiée, Vision transmet les enregistrements TLS 1.3 admissibles déjà chiffrés. Les autres données restent chiffrées. Aucun autre interrupteur Vision n'est nécessaire.

## Vision pour TCP, QUIC pour UDP

Client :

```toml
transport = "tcp"
udp_transport = "quic"
mux = false
socks_listen = "127.0.0.1:1080"
```

Serveur :

```toml
listen = "0.0.0.0:443"
udp_listen = "0.0.0.0:443"
```

Ouvrez TCP et UDP et choisissez un site QUIC/HTTP/3 accessible. Un seul processus à chaque extrémité suffit.

## QUIC pour les deux types de requêtes

```toml
transport = "quic"
```

Omettez `udp_transport` pour qu'UDP hérite de QUIC. Supprimez une ancienne surcharge ou changez-la en `quic`.

## Nœud local pour un client de type Clash

```yaml
proxies:
  - name: Umbra
    type: socks5
    server: 127.0.0.1
    port: 1080
    udp: true
```

Ajoutez-le à la liste et au groupe existants. `udp: true` autorise UDP ; TCP suit `transport`. Faites sortir directement l'adresse du serveur Umbra pour éviter une boucle. Changez un mode à la fois et testez TCP et UDP séparément.
