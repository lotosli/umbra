Le même programme fonctionne en mode client ou serveur. Choisissez la même version aux deux extrémités, puis le système et l'architecture de chaque appareil.

## Télécharger

Consultez les [versions GitHub](https://github.com/lotosli/umbra/releases). Le tableau permet d'identifier les cibles de compilation ; les fichiers disponibles dépendent de la version choisie.

| Plateforme | Architecture | Cible de compilation |
|---|---|---|
| macOS | Apple Silicon | `umbra-aarch64-apple-darwin` |
| macOS | Intel | `umbra-x86_64-apple-darwin` |
| Linux | x86_64 | `umbra-x86_64-unknown-linux-gnu` |
| Linux | aarch64 | `umbra-aarch64-unknown-linux-gnu` |
| Windows | x86_64 | `umbra-x86_64-pc-windows-msvc.exe` |

## Installer le programme

Sur macOS ou Linux, décompressez l'archive si nécessaire et rendez le programme exécutable. Vous pouvez le renommer `umbra` et le placer dans un répertoire du `PATH`. Sous Windows, lancez le fichier `.exe` dans un terminal ou ajoutez son dossier au `PATH`. Lisez les notes de version et utilisez les informations de vérification fournies avec le téléchargement.

## Compiler les sources

Utilisez la chaîne Rust 1.96.1 fixée par le dépôt :

```sh
git clone https://github.com/lotosli/umbra.git
cd umbra
cargo build --release
./target/release/umbra --help
```

Le programme se trouve dans `target/release`, avec le suffixe `.exe` sous Windows.

## Vérifier l'installation

Lancez `umbra --help`, avec le chemin complet si nécessaire. Les commandes `server`, `client` et `keygen` doivent apparaître. Passez ensuite à la génération des clés et à la configuration. Le guide de déploiement explique comment créer un service en arrière-plan.
