## Vue d’ensemble

Le processus de publication cible macOS, Linux et Windows. Choisissez l’architecture de la machine qui exécutera Umbra. Le tableau indique les cibles de compilation ; vérifiez les pièces jointes de la version GitHub choisie pour connaître les fichiers effectivement disponibles. Une cible ne garantit pas qu’une préversion donnée comporte cet artefact, et aucune signature ou somme de contrôle n’est inventée ici.

## Détails

Téléchargez depuis la page officielle des versions du projet. Sur macOS ou Linux, rendez le fichier téléchargé exécutable puis placez-le dans un répertoire du PATH, éventuellement sous le nom umbra. Sous Windows, utilisez le fichier .exe depuis un terminal. Lisez les notes et contrôlez les sommes de vérification lorsqu’elles accompagnent réellement cette version.

### Téléchargement des versions

[Téléchargement des versions](https://github.com/lotosli/umbra/releases)

| Plateforme | Architecture | Cible de compilation |
|---|---|---|
| macOS | Apple Silicon | `umbra-aarch64-apple-darwin` |
| macOS | Intel | `umbra-x86_64-apple-darwin` |
| Linux | x86_64 | `umbra-x86_64-unknown-linux-gnu` |
| Linux | aarch64 | `umbra-aarch64-unknown-linux-gnu` |
| Windows | x86_64 | `umbra-x86_64-pc-windows-msvc.exe` |

### Compilation des sources

```sh
git clone https://github.com/lotosli/umbra.git
cd umbra
cargo build --release
./target/release/umbra --help
```


## Vérification et limites

La compilation utilise la chaîne Rust 1.96.1 épinglée dans le dépôt. Clonez le dépôt public puis exécutez cargo build --release ; le programme se trouve dans target/release. Vérifiez que umbra --help affiche server, client et keygen. Les deux rôles utilisent le même binaire. Installer un fichier ne démarre aucun service et ne configure aucun écouteur : poursuivez avec votre propre identité.
