Umbra est un proxy open source à héberger vous-même. Lancez le serveur sur votre infrastructure, le client sur votre appareil, puis reliez vos applications à son proxy SOCKS5 local. Vous choisissez le serveur, le transport et les applications concernées.


Commencez par la configuration TCP minimale si vous souhaitez gérer votre serveur et y connecter certaines applications. Faites fonctionner un premier client avant d’ajouter votre outil de routage habituel ; inutile de régler tous les paramètres de transport dès le départ.
## Pourquoi utiliser Umbra ?

### Un véritable site web comme couverture

Votre client s'authentifie pour établir la connexion proxy. Les autres connexions sont transmises au site web configuré, qui leur renvoie sa réponse habituelle.

### Une seule entrée pour TCP et UDP

Un client et un serveur suffisent pour envoyer les requêtes TCP sur TCP et les requêtes UDP sur QUIC. Vos applications conservent une seule adresse SOCKS5.

### Moins d'opérations répétées

Le multiplexage permet de partager une connexion existante. Les connexions Vision dédiées peuvent transmettre directement les données TLS 1.3 déjà chiffrées lorsqu'elles remplissent les conditions requises, ce qui réduit le chiffrement externe et l'encapsulation.

### Gardez vos outils habituels

Les applications compatibles SOCKS5 se connectent directement. Un client de type Clash peut conserver son interface et ses règles, tandis qu'Umbra gère la connexion distante. Le nœud Umbra ne nécessite pas de certificat délivré par une autorité publique à demander ou à renouveler.

## Préparer votre installation

Prévoyez un serveur accessible, la même version d'Umbra aux deux extrémités, un véritable site TLS 1.3 accessible depuis le serveur et une application compatible SOCKS5. Umbra s'utilise en ligne de commande, sous licence MIT, sans compte Umbra. Vous fournissez et entretenez le serveur. Les nœuds VLESS, VMess et Trojan existants continuent à utiliser leurs clients respectifs ; une connexion Umbra nécessite Umbra aux deux extrémités.

## Commencer par une application

Suivez le démarrage rapide avant d'ajouter des règles ou QUIC. Vous choisissez les applications qui passent par le proxy. La version actuelle est **1.0.0-alpha** : conservez un programme et une configuration fonctionnels. Le proxy local n'ayant pas d'authentification par mot de passe, limitez son écoute à `127.0.0.1:1080`. Consultez le modèle de sécurité pour les détails.
