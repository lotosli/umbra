Commencez par TCP. Installez la même version sur le serveur et l'appareil client. Le client doit pouvoir joindre le serveur, et le serveur le site de couverture.


## Comment vérifier le résultat

Les deux processus doivent rester actifs, et curl doit recevoir la page demandée via le proxy SOCKS5 local. Le démarrage du client ne prouve pas à lui seul que la connexion distante fonctionne. En cas d’échec, vérifiez le port TCP du serveur et les paramètres d’identité des deux côtés avant ceux de l’application.

## 1. Générer les clés

Sur le serveur :

```sh
umbra keygen
```

Conservez `x25519_private` et `mldsa_seed` sur le serveur, dans `private_key` et `mldsa_seed`. Transmettez `x25519_public` et `mldsa_verify` au client par un canal de confiance, pour les champs `public_key` et `mldsa_verify`.

Choisissez séparément un `short_id` : une chaîne hexadécimale de longueur paire, de 16 caractères maximum. Utilisez la même valeur des deux côtés ; `keygen` ne la génère pas.

## 2. Démarrer le serveur

Créez `server.toml`. Remplacez toutes les valeurs d'identité et `cover.example` dans `dest` et `server_names` par un site TLS 1.3 accessible. Réservez la lecture du fichier au compte de service et aux administrateurs.

```toml
listen = "0.0.0.0:443"
private_key = "<X25519_PRIVATE_BASE64>"
short_ids = ["<SHORT_ID_HEX>"]
dest = "cover.example:443"
server_names = ["cover.example"]
max_time_diff = "120s"
mldsa_seed = "<MLDSA_SEED_BASE64>"
```

```sh
umbra server -c server.toml
```

Umbra vérifie le site au démarrage. Confirmez que le serveur démarre et autorisez son port TCP dans le pare-feu.

## 3. Démarrer le client

Créez `client.toml`. Remplacez `198.51.100.10:443` par l'adresse réelle du serveur et renseignez les clés, le `short_id` et le nom de site correspondants.

```toml
server = "198.51.100.10:443"
transport = "tcp"
public_key = "<X25519_PUBLIC_BASE64>"
short_id = "<SHORT_ID_HEX>"
server_name = "cover.example"
fingerprint = "chrome-latest"
mldsa_verify = "<MLDSA_VERIFY_BASE64>"
socks_listen = "127.0.0.1:1080"
```

Conservez `127.0.0.1:1080` pour que le proxy sans mot de passe reste réservé à cet appareil.

```sh
umbra client -c client.toml
```

## 4. Tester une requête

Dans un autre terminal :

```sh
curl --socks5-hostname 127.0.0.1:1080 https://example.com/
```

Après réception d'une réponse, configurez l'application en SOCKS5 sur `127.0.0.1`, port `1080`. `--socks5-hostname` transmet le nom du site au proxy. Arrêtez les processus au premier plan avec `Ctrl-C`. Validez TCP avant d'ajouter QUIC.
