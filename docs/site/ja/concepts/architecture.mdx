Umbra はローカルプロキシ、認証、リモート伝送を組み合わせます。Rust crate を分けることで、プロトコル解析、暗号処理、接続管理を個別にテストできます。

## 要求の流れ

アプリはローカル SOCKS5 に要求を送ります。クライアントは TCP または QUIC 接続を確立し、認証情報を検証します。サーバーが宛先へ接続してデータを中継します。未認証の接続はカバーサイトへ転送します。`server`、`client`、`keygen` が両端の起動と鍵生成を担当します。

## コンポーネント

`umbra-proto` は形式とアドレス、`umbra-crypto` は鍵交換、署名、導出、暗号化を担当します。`umbra-fingerprint` はプロファイルと JA3/JA4、`umbra-tls` は TLS 1.3 を扱います。

`umbra-reality` は認証、リプレイ確認、サイト情報の準備、`umbra-inner` は多重化、パディング、Vision、`umbra-transport` は TCP と QUIC を担当します。`umbra-core` が設定、SOCKS5、振り分け、リソースを統括し、`umbra` が CLI を提供します。

## 主な依存関係

```text
umbra CLI
    ↓
umbra-core
    ↓
umbra-reality · umbra-inner · umbra-transport
    ↓
umbra-tls
    ↓
umbra-crypto · umbra-fingerprint
    ↓
umbra-proto
```

`umbra-testkit` はループバックテスト、`xtask` は検査とリリースビルドを提供します。実装済み機能は現在のガイドとコードで確認してください。

## Web サイトと接続の関係

Web サイトはダウンロード、文書、リリース情報を提供します。両端はローカル設定で動作し、サイトが接続を管理したり設定を保管したりすることはありません。
