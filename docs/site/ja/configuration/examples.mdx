まずアドレス、鍵、カバーサイトを設定し、以下の断片を完全な設定に組み込んでください。

## TCP 接続を共有

```toml
transport = "tcp"
mux = true
```

複数の要求で接続を再利用します。適応型フロー制御は既定で有効で、互換性のあるサーバーが必要です。

## 独立 TCP / Vision

```toml
transport = "tcp"
mux = false
```

認証協議の後、Vision は条件を満たす暗号化済み TLS 1.3 レコードを転送します。他の通信は暗号化を維持します。追加の Vision スイッチは不要です。

## TCP は Vision、UDP は QUIC

クライアント：

```toml
transport = "tcp"
udp_transport = "quic"
mux = false
socks_listen = "127.0.0.1:1080"
```

サーバー：

```toml
listen = "0.0.0.0:443"
udp_listen = "0.0.0.0:443"
```

TCP と UDP を許可し、到達可能な QUIC/HTTP/3 サイトを使います。各端で一つのプロセスを動かします。

## 両方を QUIC に

```toml
transport = "quic"
```

`udp_transport` を省略すると QUIC を継承します。以前の指定があれば削除するか `quic` に変更します。

## Clash 系クライアントのローカルノード

```yaml
proxies:
  - name: Umbra
    type: socks5
    server: 127.0.0.1
    port: 1080
    udp: true
```

既存リストとグループに追加します。`udp: true` は UDP を許可し、TCP は `transport` に従います。ループ防止のため Umbra サーバーへは直接接続します。モードは一つずつ変更し、TCP と UDP を別々に確認します。
