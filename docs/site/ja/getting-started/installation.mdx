## 概要

リリース処理は macOS、Linux、Windows を対象とします。実行するマシンのアーキテクチャに合わせて選択してください。表はビルド対象の一覧です。特定のプレリリースに実際に添付されているファイルは、選択した GitHub Release で確認します。未確認の署名やチェックサムを提供したり、すべての対象が毎回公開されると保証したりはしません。

## 詳細

プロジェクトのリリースページから取得します。macOS と Linux では取得した正確なファイル名に実行権限を付与し、必要なら umbra に名前を変えて PATH 内へ置きます。Windows では .exe をターミナルから使用します。その版の説明と、実際に提供されているチェックサムを確認してから実行してください。

### リリースのダウンロード

[リリースのダウンロード](https://github.com/lotosli/umbra/releases)

| プラットフォーム | アーキテクチャ | ビルド対象 |
|---|---|---|
| macOS | Apple Silicon | `umbra-aarch64-apple-darwin` |
| macOS | Intel | `umbra-x86_64-apple-darwin` |
| Linux | x86_64 | `umbra-x86_64-unknown-linux-gnu` |
| Linux | aarch64 | `umbra-aarch64-unknown-linux-gnu` |
| Windows | x86_64 | `umbra-x86_64-pc-windows-msvc.exe` |

### ソースビルド

```sh
git clone https://github.com/lotosli/umbra.git
cd umbra
cargo build --release
./target/release/umbra --help
```


## 確認と制約

ソースビルドではリポジトリが固定する Rust 1.96.1 を使用します。公開リポジトリを複製し、cargo build --release を実行すると target/release に生成されます。umbra --help で server、client、keygen を確認します。両端は同じバイナリを使います。インストールだけではサービスも待ち受けも開始されないため、次に自分専用の鍵を生成してください。
