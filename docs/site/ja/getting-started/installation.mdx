同じ実行ファイルをクライアントとサーバーの両方に使います。両端で同じバージョンを選び、それぞれの OS と CPU アーキテクチャに合わせてください。

## ダウンロード

[GitHub Releases](https://github.com/lotosli/umbra/releases) から取得します。以下はビルド対象の一覧です。実際に配布されているファイルは各リリースで確認してください。

| プラットフォーム | アーキテクチャ | ビルド対象 |
|---|---|---|
| macOS | Apple Silicon | `umbra-aarch64-apple-darwin` |
| macOS | Intel | `umbra-x86_64-apple-darwin` |
| Linux | x86_64 | `umbra-x86_64-unknown-linux-gnu` |
| Linux | aarch64 | `umbra-aarch64-unknown-linux-gnu` |
| Windows | x86_64 | `umbra-x86_64-pc-windows-msvc.exe` |

## 実行ファイルを配置

macOS と Linux では必要に応じて展開し、実行権限を付けます。`umbra` に名前を変更して `PATH` の通ったディレクトリに置くと呼び出しやすくなります。Windows ではターミナルから `.exe` を実行するか、そのフォルダーを `PATH` に追加します。実行前にリリースノートを読み、公開されている検証情報でファイルを確認してください。

## ソースからビルド

リポジトリで指定された Rust 1.96.1 を使います。

```sh
git clone https://github.com/lotosli/umbra.git
cd umbra
cargo build --release
./target/release/umbra --help
```

実行ファイルは `target/release` に生成されます。Windows では `.exe` が付きます。

## インストールを確認

必要に応じてフルパスで `umbra --help` を実行し、`server`、`client`、`keygen` が表示されることを確認します。次に鍵を生成し、両端を設定します。バックグラウンド実行は運用ガイドで設定できます。
