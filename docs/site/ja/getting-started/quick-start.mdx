最初は TCP を使います。サーバーとクライアントに同じバージョンをインストールしてください。クライアントからサーバーへ、サーバーからカバーサイトへ接続できる必要があります。

## 1. 鍵を生成

サーバーで実行します。

```sh
umbra keygen
```

`x25519_private` と `mldsa_seed` はサーバーだけで保管し、`private_key` と `mldsa_seed` に設定します。`x25519_public` と `mldsa_verify` は信頼できる経路でクライアントへ渡し、`public_key` と `mldsa_verify` に設定します。

`short_id` は別途選びます。16 文字以内で、文字数が偶数の 16 進数文字列を両端に同じ値で設定してください。`keygen` はこの値を生成しません。

## 2. サーバーを起動

`server.toml` を作成します。鍵のプレースホルダーをすべて置き換え、`dest` と `server_names` の `cover.example` を到達可能な TLS 1.3 サイトに変更します。ファイルを読めるのはサービス実行ユーザーと管理者だけにしてください。

```toml
listen = "0.0.0.0:443"
private_key = "<X25519_PRIVATE_BASE64>"
short_ids = ["<SHORT_ID_HEX>"]
dest = "cover.example:443"
server_names = ["cover.example"]
max_time_diff = "120s"
mldsa_seed = "<MLDSA_SEED_BASE64>"
```

```sh
umbra server -c server.toml
```

起動時にサイトが検査されます。起動の成功を確認し、設定した TCP ポートをファイアウォールで許可します。

## 3. クライアントを起動

`client.toml` を作成し、`198.51.100.10:443` を実際のアドレスに変更します。対応する鍵、`short_id`、サイト名を入力してください。

```toml
server = "198.51.100.10:443"
transport = "tcp"
public_key = "<X25519_PUBLIC_BASE64>"
short_id = "<SHORT_ID_HEX>"
server_name = "cover.example"
fingerprint = "chrome-latest"
mldsa_verify = "<MLDSA_VERIFY_BASE64>"
socks_listen = "127.0.0.1:1080"
```

パスワードのないローカルプロキシをこの端末だけで使うため、`127.0.0.1:1080` を維持します。

```sh
umbra client -c client.toml
```

## 4. リクエストを試す

別のターミナルで実行します。

```sh
curl --socks5-hostname 127.0.0.1:1080 https://example.com/
```

応答を受け取れたら、アプリのプロキシを SOCKS5、アドレス `127.0.0.1`、ポート `1080` に設定します。`--socks5-hostname` は宛先名をプロキシに渡します。前面で動くプロセスは `Ctrl-C` で終了できます。TCP の動作を確認してから QUIC を追加してください。
