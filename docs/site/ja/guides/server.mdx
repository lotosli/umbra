サーバーは Umbra クライアントを認証し、アプリが要求した宛先へ接続します。それ以外の接続は `dest` に設定したサイトへ転送します。

## サイトを選ぶ

サーバーから実在する TLS 1.3 サイトにアクセスできることを確認します。そのドメインを `server_names` とクライアントの `server_name` に使います。QUIC を利用する場合は、そのサイトの QUIC/HTTP/3 サービスにも到達できる必要があります。

## 設定ファイルを作る

`umbra keygen` を実行し、クイックスタートに従って `short_id` を選びます。値と `cover.example` を置き換えて `server.toml` に保存します。

```toml
listen = "0.0.0.0:443"
private_key = "<X25519_PRIVATE_BASE64>"
short_ids = ["<SHORT_ID_HEX>"]
dest = "cover.example:443"
server_names = ["cover.example"]
max_time_diff = "120s"
mldsa_seed = "<MLDSA_SEED_BASE64>"
```

`listen` が TCP の待ち受け先です。秘密鍵と署名シードを含むファイルの読み取り権限を制限してください。

## 起動して確認

```sh
umbra server -c server.toml
```

起動時のサイト検査に失敗した場合は、宛先、ドメイン、ネットワークを確認します。`prebuild = false` で無効になるのは定期更新だけで、起動時検査は行われます。ポートとファイアウォールを確認し、設定の一致するクライアントで試してください。通常のブラウザーや未認証 TLS プローブがカバーサイトの証明書を受け取るのは正常です。

## 必要なら QUIC を有効化

完全な設定に `udp_listen = "0.0.0.0:443"` を追加します。TCP と UDP は同じポート番号を使用できます。UDP を許可し、サイトの QUIC を確認してください。前面で動作を確認した後、バックグラウンドサービスに移行します。
