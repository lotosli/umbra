対象のリリースノートを読み、現在の両端バージョンを記録し、動作する設定と実行ファイルを保存します。互換性を保てる更新日程を組んでください。

## 1.0.0-alpha への更新

暗号化処理、共有接続のスケジューリング、QUIC 受信が改善されています。適応型 mux は消費量と往復時間に応じ、メモリ予算内で受信ウィンドウを調整します。利用するには両端を更新します。

```toml
[performance]
adaptive_mux = true
quic_congestion = "bbr"
```

`adaptive_mux = false` は旧 mux を明示的に選択します。`mux = false` は引き続き独立 Vision、`udp_transport` は UDP 専用の選択です。

## 古いバージョンからの更新

0.0.8 は X25519MLKEM768 の鍵共有データと共有秘密の順序を修正しており、両端の更新が必要です。途中のリリースノートも確認してください。ローテーションが必要なければ鍵、`short_id`、サイト名を継続利用できます。

## 更新後の確認

実際に起動したファイルを確認し、SOCKS5 経由の HTTPS、設定済み UDP、再起動後の復帰を試します。性能比較では経路と負荷を揃えます。QUIC の BBR と OS の TCP 輻輳制御は別設定です。戻す場合も両端の互換性を確認してください。
