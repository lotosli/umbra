以下片段用于合并到已有的完整配置。先按[快速开始](/zh-hans/docs/getting-started/quick-start/)填好服务器地址、密钥和掩护网站，再选择需要的模式。

## 多个请求复用 TCP 连接

```toml
transport = "tcp"
mux = true
```

适合希望减少重复建连的场景。当前版本默认使用自适应流控，需要匹配版本的服务端。

## 独立 TCP / Vision 连接

```toml
transport = "tcp"
mux = false
```

对符合条件的 TLS 1.3 流量，Vision 在认证协商完成后直接转发已加密记录，减少重复加密。其他流量继续通过加密通道传输。设置 `mux = false` 即可选择此模式。

## TCP 使用 Vision，UDP 使用 QUIC

客户端：

```toml
transport = "tcp"
udp_transport = "quic"
mux = false
socks_listen = "127.0.0.1:1080"
```

服务端同时启用两个监听：

```toml
listen = "0.0.0.0:443"
udp_listen = "0.0.0.0:443"
```

一组客户端与服务端即可处理这两条路径。服务端防火墙需要放行相应 TCP、UDP 端口，掩护网站需要支持可访问的 QUIC/HTTP/3 服务。

## TCP 和 UDP 都使用 QUIC

```toml
transport = "quic"
```

省略 `udp_transport`，UDP 就会继承 `transport`。如果原配置中已有该字段，请删除它或显式改为 `quic`。

## 在 Clash 类客户端中添加本地节点

```yaml
proxies:
  - name: Umbra
    type: socks5
    server: 127.0.0.1
    port: 1080
    udp: true
```

将节点加入现有列表和代理组。`udp: true` 允许发送 UDP 请求；TCP 请求继续按 Umbra 的 `transport` 设置处理。将 Umbra 服务器地址设为直连，避免代理循环。

## 验证配置

每次只切换一种模式，用同一个应用验证连接。TCP 和 UDP 分别测试；需要优化时再调整填充、分块或性能参数。
