客户端与服务端使用同一个 Umbra 程序，通过不同子命令启动。为两端选择同一版本，再按各自的操作系统和处理器架构下载。

## 下载程序

打开[GitHub 发布页面](https://github.com/lotosli/umbra/releases)，在所选版本的附件中查找对应文件。下表帮助你识别文件名；可下载的平台以该版本附件为准。

| 平台 | 架构 | 文件名对应的构建目标 |
|---|---|---|
| macOS | Apple Silicon | `umbra-aarch64-apple-darwin` |
| macOS | Intel | `umbra-x86_64-apple-darwin` |
| Linux | x86_64 | `umbra-x86_64-unknown-linux-gnu` |
| Linux | aarch64 | `umbra-aarch64-unknown-linux-gnu` |
| Windows | x86_64 | `umbra-x86_64-pc-windows-msvc.exe` |

## 安装到设备

- **macOS、Linux：** 如果附件是压缩包，先解压。为下载的程序添加执行权限；可以将其重命名为 `umbra`，放入 `PATH` 中的目录，方便在终端调用。
- **Windows：** 如果附件是压缩包，先解压。在终端中运行对应的 `.exe`；也可以将其所在目录加入 `PATH`。

运行前查看版本说明，并按发布页面提供的信息核对文件。

## 从源码构建

本仓库固定使用 Rust 1.96.1。准备好对应工具链后运行：

```sh
git clone https://github.com/lotosli/umbra.git
cd umbra
cargo build --release
./target/release/umbra --help
```

构建完成的程序位于 `target/release`。Windows 下可执行文件带有 `.exe` 后缀。

## 确认安装成功

运行 `umbra --help`；如果尚未加入 `PATH`，请使用程序的实际路径。帮助中应能看到 `server`、`client`、`keygen` 三个子命令。

接下来生成密钥、配置两端并启动程序。需要开机运行时，再按[部署与运维](/zh-hans/docs/guides/deployment/)设置后台服务。
