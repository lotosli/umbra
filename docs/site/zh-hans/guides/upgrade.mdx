## 概览

当前源码版本为 1.0.0-alpha。升级前阅读目标发布说明，记录客户端和服务端版本，妥善备份配置，并保留已经验证的旧二进制。涉及线格式变化时需要按两端一起升级来安排。网站显示新版本，不代表远程机器已经运行该版本，也不应替代实际验证。

## 详细说明

0.0.8 修正了 X25519MLKEM768 的密钥份额和共享秘密顺序，旧的反向顺序不再支持，因此两端必须升级。当前 alpha 增加可复用的硬件加速 TLS 密码上下文、按就绪流调度的 mux、受预算约束的启动窗口和 QUIC 批量入队。新 TCP mux 会话默认启用 adaptive_mux=true，需要升级后的服务端；设为 false 可明确选用旧 mux，但不会自动重放业务或降级。

### 可选性能配置表

```toml
[performance]
adaptive_mux = true
quic_congestion = "bbr"
```


## 验证与边界

没有轮换要求时，身份密钥、short ID 和 SNI 可继续使用。mux=false 仍选择独立 Vision，udp_transport 仍单独控制 UDP。升级后检查普通 TCP 请求、已配置的 UDP 和退出重启行为。比较性能时应保持路径与负载可比。QUIC 默认 Quinn BBR 与 Linux TCP 拥塞控制相互独立，不能据此保证吞吐提升。
