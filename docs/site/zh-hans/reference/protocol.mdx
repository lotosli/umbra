选型时先看三件事：网络允许哪些连接、准备如何维护服务器，以及现有应用如何接入。Umbra 将网站掩护、TCP/Vision、QUIC 和 SOCKS5 入口放在一套客户端与服务端中，适合希望自行管理这套连接的用户。

以下按 Umbra 1.0.0-alpha 和列出的官方资料说明功能差异。Xray 一栏限定为 VLESS + REALITY + Vision 的 TCP 组合，便于与具体部署方式对照。

## 部署与传输对照

| 方案 | 主要特点 | 部署要点 | TCP 与 UDP |
| --- | --- | --- | --- |
| Umbra | 真实网站掩护；一个本地入口可配置两条传输路径 | 自建两端，管理密钥和掩护网站；无需申请节点 CA 证书 | TCP 可选连接复用或 Vision；UDP 可单独使用 QUIC |
| Xray + VLESS + REALITY + Vision | 在 Xray 中组合 REALITY 与 Vision | 配置核心、密钥和目标网站，配合支持相应配置的客户端 | 此处为 TCP 外层；UDP 请求按 flow 和客户端配置处理 |
| VMess AEAD | 协议提供加密，可搭配不同传输 | 使用支持对应协议与传输的客户端；叠加 TLS 时配置相应认证 | 支持 TCP、UDP 请求，外层由配置决定 |
| Trojan | 使用 TLS，并支持未认证请求回落到网站服务 | 常见部署维护域名、证书和私钥 | TCP 与 UDP 请求通过 TLS/TCP 承载 |
| Shadowsocks AEAD / 2022 | 基于密钥的加密代理 | 配置密钥与匹配客户端；额外插件按需配置 | 基础协议支持 TCP、UDP；插件支持范围单独确认 |
| Hysteria 2 | 基于 QUIC；未认证时提供 HTTP/3 网站行为 | 需要可用的 UDP 路径与 TLS 配置 | TCP 使用可靠 QUIC 流，UDP 使用不可靠数据报 |

对应的官方资料：[Xray VLESS/Vision](https://xtls.github.io/config/outbounds/vless.html)、[VMess](https://www.v2fly.org/developer/protocols/vmess.html)、[Trojan](https://trojan-gfw.github.io/trojan/protocol)、[Shadowsocks 2022](https://shadowsocks.org/doc/sip022.html)、[Hysteria 2](https://v2.hysteria.network/docs/developers/Protocol/)。

## Umbra 可以简化哪些工作

### 两条路径，共用一个本地入口

配置 `transport = "tcp"`、`udp_transport = "quic"` 和 `mux = false` 后，TCP 请求使用 Vision，UDP 请求使用 QUIC。应用只需要一个 SOCKS5 代理地址，两端各运行一个 Umbra 实例。

### 减少证书维护

Umbra 使用身份密钥和临时证书绑定，节点无需自行申请和续期公网 CA 证书。你维护两端密钥，并选择可达的真实网站。启用 QUIC 时，目标网站也需要支持 QUIC。

### 沿用应用与规则

支持 SOCKS5 的应用可直接接入；Clash 类客户端可以保留规则和界面，将远端传输交给 Umbra。连接两端使用 Umbra，现有其他协议节点仍由对应客户端处理。

### 按请求选择连接方式

TCP mux 复用连接，减少重复建连；独立 Vision 连接针对符合条件的 TLS 1.3 流量减少重复加密。选择方法见[传输模式](/zh-hans/docs/concepts/transports/)。

## 按已有环境选择

- **已经使用 Xray 与 REALITY：** 先评估现有路由、客户端和配置管理需求。Umbra 的重点是一套客户端与服务端中的单入口双传输体验。
- **已有 VMess 应用：** 确认正在使用的传输组合和客户端支持，再评估迁移工作量。
- **希望按常规 TLS 服务维护：** 可以了解 Trojan 的证书与回落部署方式。
- **希望采用密钥配置的加密代理：** 可以了解 Shadowsocks，并按需要评估额外插件。
- **主要考虑 QUIC 路径：** 对照 Hysteria 2 的数据报与 Umbra 的可靠流方式，测试实际 UDP 应用的表现。

Umbra 当前以 Alpha 命令行程序交付。选型还应考虑图形界面、移动端与订阅管理等现有需求。

## UDP 的一个关键差别

Hysteria 2 使用不可靠数据报承载 UDP；Umbra 当前把 UDP 关联数据封装在可靠 QUIC 流中。前者允许丢失数据报，后者会在同一流中等待缺失数据重传。对通话、游戏或其他实时应用，应在实际网络上比较延迟与丢包表现。[Hysteria 2 协议](https://v2.hysteria.network/docs/developers/Protocol/)
