用戶端與伺服器端使用同一個 Umbra 程式，通過不同子指令啟動。為兩端選擇同一版本，再按各自的操作系統和處理器架構下載。

## 下載程式

打開[GitHub 發佈頁面](https://github.com/lotosli/umbra/releases)，在所選版本的附件中尋找對應檔案。下表幫助你識別檔案名；可下載的平台以該版本附件為準。

| 平台 | 架構 | 檔案名對應的建置目標 |
|---|---|---|
| macOS | Apple Silicon | `umbra-aarch64-apple-darwin` |
| macOS | Intel | `umbra-x86_64-apple-darwin` |
| Linux | x86_64 | `umbra-x86_64-unknown-linux-gnu` |
| Linux | aarch64 | `umbra-aarch64-unknown-linux-gnu` |
| Windows | x86_64 | `umbra-x86_64-pc-windows-msvc.exe` |

## 安裝到裝置

- **macOS、Linux：** 如果附件是壓縮包，先解壓。為下載的程式添加執行權限；可以將其重命名為 `umbra`，放入 `PATH` 中的目錄，方便在終端機調用。
- **Windows：** 如果附件是壓縮包，先解壓。在終端機中執行對應的 `.exe`；也可以將其所在目錄加入 `PATH`。

執行前查看版本說明，並按發佈頁面提供的資訊核對檔案。

## 從原始碼建置

本儲存庫固定使用 Rust 1.96.1。準備好對應工具鏈後執行：

```sh
git clone https://github.com/lotosli/umbra.git
cd umbra
cargo build --release
./target/release/umbra --help
```

建置完成的程式位於 `target/release`。Windows 下可執行檔案帶有 `.exe` 後綴。

## 確認安裝成功

執行 `umbra --help`；如果尚未加入 `PATH`，請使用程式的實際路徑。幫助中應能看到 `server`、`client`、`keygen` 三個子指令。

接下來產生金鑰、設定兩端並啟動程式。需要開機執行時，再按[部署與運維](/zh-hant/docs/guides/deployment/)設定背景服務。
