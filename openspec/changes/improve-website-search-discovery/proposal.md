# Proposal

## Why

The public site is accessible in seven languages, but slogan-only search titles and vague comparisons make its purpose and setup requirements hard to understand. The user approved the complete SEO/GEO plan, including concrete comparison copy, on 2026-09-18 and authorized implementation and publication.

## What Changes

- Add independent localized search titles, source-backed structured data, visible document dates and accurate sitemap modification dates.
- Normalize root language redirects and cache headers, retain multilingual canonical URLs, and add a repeatable discovery audit.
- Rewrite comparisons around user decisions and strengthen six task-oriented guides in seven languages.
- Add a privacy-preserving, opt-in measurement interface and operational baseline/AI evaluation materials; inspect available external account access without inventing dashboard results.
- Validate, publish and record production evidence. No breaking runtime changes.

## Capabilities

### New Capabilities

- `website-search-discovery`: Search metadata, structured facts, content dates, discovery verification and bounded measurement.

### Modified Capabilities

None. Existing visual and routing fidelity requirements remain intact.

## Impact

Affects apps/web, docs/site and website operations documentation. No proxy runtime changes or new production dependencies. External Search Console/Bing/Cloudflare controls depend on authenticated account access. Future 30/60/90-day outcome analysis requires elapsed time and collected data and is not a publication gate.
