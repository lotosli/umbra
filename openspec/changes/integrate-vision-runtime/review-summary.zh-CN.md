# Vision 0.0.7 实施结果

用户已确认协议方案，并进一步要求删除旧实现、取消性能比较、直接发布部署0.0.7及补充线上测试。

- TCP `mux=false` 直接使用真正的 Vision 拼接；`mux=true` 保留多路复用。没有额外 Vision 开关。
- 旧 solo 中继和未接入运行时的 helper 已删除。新客户端和服务端已部署。
- 独立 TLS 端点完成双向256 KiB数据传输，原始线上密文逐字节一致，切换后外层加密调用计数停止。
- 475项测试通过，行覆盖率94.77%，两个新解析器各通过10,000次AddressSanitizer模糊测试。
- 3个顺序和6个并发线上HTTPS请求成功，两端日志均确认真实拼接且外层计数不再增长。

不提供性能排名或提速比例，也不宣称内核零拷贝。完整[验收记录](verification.md)、[协议规范](../../../docs/vision-runtime-wire-v2.md)及[任务进度](tasks.md)。
